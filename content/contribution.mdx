문서를 추가·수정하는 방법과, MDX에서 바로 쓸 수 있는 컴포넌트 목록입니다.

## 수정 모드 (가장 쉬운 방법)

**개발 서버로 실행하면 브라우저에서 바로 문서를 편집할 수 있는 수정 모드가 켜집니다.**

```bash
npm run dev
```

개발 환경에서는 다음이 나타납니다.

- 헤더 우측의 **✎ Edit** 버튼 → `/edit` 관리 화면
- 각 문서 페이지 우하단의 **✎ 수정** 플로팅 버튼 → 그 문서 편집기로 바로 이동

<Callout type="info" title="수정 모드에서 할 수 있는 것">
- **단일 문서 편집** — 왼쪽 MDX 원문 / 오른쪽 실시간 프리뷰. <Kbd>/</Kbd> 로 컴포넌트 슬래시 메뉴, <Kbd>⌘</Kbd> + <Kbd>S</Kbd> 로 저장
- **문서 추가·삭제** 와 **사이드바 관리** — 드래그로 문서·카테고리 순서 변경, 카테고리 추가/이름변경
- **홈 화면(히어로) 편집** — 제목·설명·버튼 문구 수정

저장하면 `content/` 의 실제 `.mdx` 파일에 그대로 기록됩니다.
</Callout>

<Callout type="warn">
수정 모드는 **개발 환경에서만** 동작합니다. 배포된 사이트에서는 `/edit` 이 열리지 않습니다(404).
</Callout>

## 파일로 직접 추가하기

수정 모드를 쓰지 않고 직접 파일을 만들어도 됩니다. `content/docs/` 아래에 `.mdx`
파일을 하나 만들면 사이드바·목차·검색이 자동으로 갱신됩니다.

```mdx
---
title: 문서 제목
description: 사이드바·검색에 쓰이는 한 줄 설명
category: 영상 송출    # 사이드바 그룹
order: 2              # 그룹 내 순서
---

여기에 내용을 마크다운으로 작성합니다.
```

<Callout type="tip">
카테고리 순서는 `content/sidebar.json` 에서 관리합니다(수정 모드의 사이드바 드래그가
이 파일을 자동으로 갱신합니다). 폴더로 묶어도 됩니다 — 예) `content/docs/audio/mixer.mdx` → `/docs/audio/mixer`
</Callout>

## 사용 가능한 컴포넌트

별도 import 없이 MDX 안에서 바로 사용할 수 있습니다. (수정 모드 에디터에서는 <Kbd>/</Kbd> 슬래시 메뉴로 골라 넣을 수 있습니다.)

### Callout — 강조 블록

```mdx
<Callout type="tip" title="선택">내용</Callout>
```

`type` 은 `note` · `info` · `tip` · `warn` · `danger` 중 하나입니다.

### Steps — 절차 안내

```mdx
<Steps>
  <Step title="첫 번째">설명</Step>
  <Step title="두 번째">설명</Step>
</Steps>
```

### Figure — 이미지 블록

```mdx
<Figure src="/assets/onair/00-main.webp" alt="설명" caption="캡션" />
```

클릭하면 확대됩니다. 이미지는 `public/` 폴더에 둡니다.

### Card / CardGrid — 링크 카드

```mdx
<CardGrid>
  <Card href="/docs/intro" title="시작하기">설명</Card>
</CardGrid>
```

### 인라인 — Kbd, Badge

```mdx
<Kbd>Ctrl</Kbd> + <Kbd>C</Kbd> 그리고 <Badge>LIVE</Badge>
```

### 표 · 코드 블록

표는 GFM 문법을 그대로 쓰고, 코드 펜스(```)에 언어를 적으면 문법 강조 + 복사
버튼이 자동으로 붙습니다.
