새 문서를 추가하거나 기존 문서를 다듬는 방법, 그리고 MDX에서 바로 쓸 수 있는
컴포넌트 목록입니다.

## 새 문서 추가하기

`content/docs/` 아래에 `.mdx` 파일을 하나 만들면 끝입니다. 사이드바와 목차는
자동으로 생성됩니다.

```mdx
---
title: 문서 제목
description: 사이드바·검색에 쓰이는 한 줄 설명
category: 송출        # 사이드바 그룹 (시작하기 / 장비 / 송출 / 음향 / 조명·영상 / 운영)
order: 2              # 그룹 내 순서
---

여기에 내용을 마크다운으로 작성합니다.
```

<Callout type="tip">
폴더로 묶어도 됩니다. 예) `content/docs/audio/mixer.mdx` → `/docs/audio/mixer`
</Callout>

## 사용 가능한 컴포넌트

별도 import 없이 MDX 안에서 바로 사용할 수 있습니다.

### Callout — 강조 블록

```mdx
<Callout type="tip" title="선택">내용</Callout>
```

`type` 은 `note` · `info` · `tip` · `warn` · `danger` 중 하나입니다.

### Steps — 절차 안내

```mdx
<Steps>
  <Step title="첫 번째">설명</Step>
  <Step title="두 번째">설명</Step>
</Steps>
```

### Figure — 이미지 컨트롤 블록

```mdx
<Figure src="/shots/obs.png" alt="설명" caption="캡션" width={1280} height={720} />
```

클릭하면 확대됩니다. 이미지는 `public/` 폴더에 둡니다.

### Card / CardGrid — 링크 카드

```mdx
<CardGrid>
  <Card href="/docs/obs-setup" title="OBS 세팅">설명</Card>
</CardGrid>
```

### 인라인 — Kbd, Badge

```mdx
<Kbd>Ctrl</Kbd> + <Kbd>C</Kbd> 그리고 <Badge>LIVE</Badge>
```

### 코드 블록

코드 펜스(```)에 언어를 적으면 문법 강조 + 복사 버튼이 붙습니다.
