## 오디오 믹서

<Figure src="/assets/gear/AUDIO MIXER/주요기능.webp" alt="오디오 믹서" caption="오디오 믹서 — 프로그램(PGM)용 10채널" />

영상 입력 4채널, NET/USB, 외부 오디오, 동영상 등 **10채널**의 소리를 섞어 내보냅니다.

| 하려는 것 | 방법 |
| --- | --- |
| 음소거 | 채널 아래 스피커 표시 클릭. 위쪽 빨간 막대가 꺼지면 막힌 것 |
| 크기 조절 | 세로 막대를 올리고 내림 |
| 좌우 균형 | 위쪽 좌우 막대를 옮김 |

## 출력 모드

| 모드 | 나가는 소리 |
| --- | --- |
| 믹스 | 화면과 상관없이 모든 채널을 섞어서 |
| 연동 | 지금 송출 중인(PGM) 채널의 소리만 |
| 고정 | 화면과 상관없이 정해 둔 채널만 (채널 이름 클릭) |

PPT·인터넷 같은 PC 화면 송출의 소리는 **PC 모드 오디오** 로 크기를 맞춥니다.

## 영상과 소리가 어긋날 때

외부 XLR·Phone 출력은 0~1초까지 **지연**을 줄 수 있습니다. 화면보다 소리가 빠르면 조금씩 늘려 맞추세요.

<Callout type="warn">
지연은 **외부 XLR / Phone 출력에만** 적용됩니다.
</Callout>

## 배경 음악

배경 오디오는 화면이 무엇이든 **정해 둔 음악을 계속** PGM 으로 내보냅니다. 점심 방송 BGM 에 씁니다.

갤러리에 곡을 올리고 골라서 재생합니다. 반복 재생도 됩니다. 형식은 **mp3 · wma** 입니다.

## 소리가 안 날 때

<Steps>
  <Step title="음소거 확인">
    해당 채널 위 빨간 막대가 꺼져 있지 않은지 봅니다.
  </Step>
  <Step title="출력 모드 확인">
    **연동** 모드면 지금 송출 중인 채널의 소리만 나갑니다. 다른 채널 소리가 필요하면 믹스나 고정으로 바꿉니다.
  </Step>
  <Step title="연결 확인">
    외부 믹서로 나가는 소리면 XLR 극성과 연결을 확인합니다. ([켜고 끄기·연결](/docs/gear-setup))
  </Step>
</Steps>
