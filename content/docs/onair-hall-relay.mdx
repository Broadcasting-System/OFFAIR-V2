강당 행사 소리를 **교실 스피커로 실시간** 내보내요. 강당에 다 못 들어온 학년이 교실에서 들을 수 있어요. 소리는 [강당 녹음](/docs/onair-recording-setup)과 같은 입력(강당 노트북의 M-Track)에서 가져와요.

```
강당 콘솔 녹음 버스 → M-Track → 강당 노트북 → ONAIR 서버 → 방송 앰프 → 고른 교실 스피커
```

<Callout type="warn" title="지금은 말로만 켜요">
컨트롤 화면에는 아직 중계 버튼이 없어요(화면은 디자인 중이에요). 지금은 **CUE 도우미** 나 **[ONAIR MCP](/docs/onair-mcp)** 에 말해서 켜고 꺼요.
</Callout>

## 준비

- 강당 노트북이 켜져 있고 **ONAIR Bridge** 창이 떠 있어요.
- M-Track 이 노트북에 꽂혀 있고, **HALL › 녹음·녹화** 에서 강당 입력 미터가 움직여요. 연결은 [강당 녹음 장비 연결](/docs/onair-recording-setup)을 봐요.
- 콘솔 녹음 버스(마이크·음악)에 소리가 들어가고 있어요.

## 켜기

<Steps>
  <Step title="말하기">
    CUE 나 MCP 에 이렇게 말해요. "강당 소리를 3학년 교실로 90분 중계해 줘"
  </Step>
  <Step title="내용 확인">
    어느 스피커로 몇 분 동안 내보낼지 보여 줘요. 맞으면 "응, 해 줘"라고 답해요. CUE 는 카드의 확인 버튼을 눌러요.
  </Step>
  <Step title="시작">
    스피커가 켜지고 딩동댕이 울린 뒤 강당 소리가 나가요.
  </Step>
</Steps>

| 정할 것 | 범위 |
| --- | --- |
| 스피커 | 교실·학년·특별실 이름 (여러 곳 가능) |
| 시간 | 1~180분, 말하지 않으면 120분 |

## 끄기

"중계 멈춰 줘"라고 말해요. 끝 딩동댕이 울리고 스피커가 원래대로 돌아가요.

아래 경우에는 **저절로 끝나요.**

| 끝나는 까닭 | 설명 |
| --- | --- |
| 정한 시간이 다 됨 | 최대 180분 |
| 다음 시보 직전 | 종이 먼저예요. 종 몇 초 전에 끝나요 |
| 소리가 8초 끊김 | 강당 노트북이 꺼졌거나 망이 끊겼을 때 |

시보 때문에 끝났으면 종이 울린 뒤 다시 켜요.

## 규칙

- **강당 스피커는 고를 수 없어요.** 강당 소리를 강당에 다시 틀면 마이크로 들어가 하울링이 나요.
- **마이크 방송과 동시에 못 해요.** 다른 방송(마이크·TTS·선생님 방송)이 나가는 중이면 시작하지 않아요. 중계 중에는 다른 방송을 못 해요.
- 소리 크기는 ONAIR 가 아니라 **콘솔 녹음 버스** 에서 맞춰요. 음악도 효과 없이 그대로 나가요.
- 소리는 두 입력(마이크·음악)을 섞은 모노로 나가요.
- 권한은 **부원 이상** 이에요.

## 안 될 때

| 메시지 | 할 일 |
| --- | --- |
| 강당 노트북에서 소리가 들어오지 않아요 | 시작 6초 안에 소리가 안 오면 스피커를 켜지 않아요. 녹음 화면 미터, M-Track USB, 콘솔 녹음 버스를 봐요 |
| 강당 노트북에 연결하지 못했어요 | 강당 노트북 전원과 ONAIR Bridge 창을 봐요 |
| 다른 방송이 진행 중이에요 | 그 방송이 끝난 뒤 다시 켜요 |
| 같은 공간(강당) 스피커는 고를 수 없어요 | 강당 스피커를 빼고 다시 말해요 |
| 이미 중계 중이에요 | 먼저 멈춘 뒤 다시 켜요 |
