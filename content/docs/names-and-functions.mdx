방송 송출 프로그램의 화면은 여러 기능 영역으로 나뉩니다. 각 영역의 위치와 역할을 익혀 두면 메뉴를 훨씬 빠르게 다룰 수 있습니다.

<Figure src="/assets/software/명칭및기능.webp" alt="방송 소프트웨어 화면 구성" caption="프로그램 전체 화면 구성" />

## 주요 영역

| 영역 | 위치 | 기능 |
| --- | --- | --- |
| 시스템 상태 표시 | 최상단 | 방송 상태·통신 연결·전원·타이머 등 전반적인 동작 상태 표시 |
| INPUT MIXER | 좌상단 | 16개 입력 채널 선택·제어. 실시간 볼륨, 감청, 이퀄라이저, 음소거 |
| OUTPUT MIXER | 가운데 | 8개 출력 채널 제어. INPUT과 동일한 기능 |
| 환경 설정 | 우하단 | 종·예약 방송 등을 관리하는 메뉴 버튼 |

<Callout type="info">
믹서는 **16 IN / 8 OUT** 구조입니다. INPUT MIXER에서 16개 입력을 받아 채널별로 제어하고, OUTPUT MIXER에서 8개 출력으로 내보냅니다.
</Callout>
