방송실 영상 송출의 중심은 **LBS-2000 통합 방송 시스템** 입니다. 카메라·노트북·동영상·이미지·PPT 같은 여러 소스를 받아 골라서 내보내고, 자막을 얹고, 녹화까지 한 대에서 처리합니다.

## LBS-2000 이 하는 일

| 항목 | 내용 |
| --- | --- |
| 입력 | 영상 6채널 (HDMI 4 · YPbPr 2, 3·4번은 겸용) + 네트워크/USB 2채널 |
| 출력 | 서로 다른 화면을 보낼 수 있는 출력 3개 |
| 전환 | 프리뷰에 올려 두고 CUT·TAKE 로 송출, 전환 효과 약 40가지 |
| 소리 | XLR 밸런스 입·출력, 프로그램(PGM)용 10채널 믹서 |
| 그 밖에 | 단문 자막, 순서 송출, 예약 송출, 녹화 |

<Callout type="info">
영상 처리를 하드웨어에서 하기 때문에 입력에서 출력까지 **지연이 거의 없습니다.** 실시간 행사 송출에 맞는 장비입니다.
</Callout>
