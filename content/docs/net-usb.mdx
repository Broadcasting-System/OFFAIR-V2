## 개요

인터넷 유튜브 영상과 USB 카메라·BLC-300 TX를 영상 소스로 사용할 수 있는 채널이 **2개(Net1·Net2)** 있습니다.

## 네트워크(URL) 영상

<Figure src="/assets/gear/NET/NET.png" alt="네트워크 URL 설정" caption="Net 채널 URL 지정" />

인터넷 동영상은 유튜브 수신이 가능합니다.

<Steps>
  <Step title="환경 설정 열기">
    IP 채널 5·6번의 환경 설정 기어 아이콘을 클릭합니다.
  </Step>
  <Step title="IP 수신 모드 선택">
    IP 수신 모드를 선택하면 하단에 URL 주소 입력창이 나타납니다.
  </Step>
  <Step title="주소 입력">
    수신 가능한 주소를 선택해 URL 입력을 완료합니다.
  </Step>
</Steps>

### 새 유튜브 주소 입력

<Steps>
  <Step title="영상 수신 확인">
    인터넷에서 유튜브에 접속해 원하는 동영상을 재생합니다.
  </Step>
  <Step title="주소 복사">
    수신이 확인되면 브라우저 상단 주소창을 클릭해 주소를 복사합니다.
  </Step>
  <Step title="붙여넣기">
    메뉴로 돌아가 입력 5·6번의 URL 주소창에 붙여넣어 새 주소를 입력합니다.
  </Step>
</Steps>

## USB 장치 영상·음성 입력

Device 탭에서 외부 USB 카메라나 컨버터 출력을 영상으로 입력할 수 있습니다.

<Steps>
  <Step title="USB 입력 모드 선택">
    USB 카메라·컨버터를 연결한 뒤, 입력 5·6번 채널의 환경 설정에서 Device 탭의 USB 입력 모드를 선택합니다.
  </Step>
  <Step title="해상도·오디오 설정">
    입력 해상도와 오디오 입력 방식을 설정합니다.
  </Step>
  <Step title="미리보기 확인">
    입력 미리보기 창에 화면이 보이는지 확인하고 설정을 닫습니다.
  </Step>
</Steps>

<Callout type="warn">
입력 장치 목록에 USB 장치가 보이지 않으면, 해당 제품의 **드라이버가 설치되었는지** 확인하세요.
</Callout>
