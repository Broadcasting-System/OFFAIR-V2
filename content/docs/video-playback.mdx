## 개요

동영상 재생 기능은 PC에 저장된 미디어 파일을 재생합니다. HDD에 저장된 동영상은 **DDR** 미디어 채널로 등록해 송출할 수 있습니다.

## DDR 동영상 재생

<Figure src="/assets/gear/동영상 송출/동영상 송출1.png" alt="DDR 동영상 등록" caption="DDR 폴더에서 파일 등록" />

<Steps>
  <Step title="DDR 탭 선택">
    모드 프리셋 창에서 DDR1 또는 DDR2 탭 폴더를 선택합니다.
  </Step>
  <Step title="파일 열기">
    파일 열기 아이콘을 눌러 재생할 파일을 선택합니다.
  </Step>
  <Step title="미리보기 등록">
    갤러리의 동영상을 두 번 클릭하면 DDR 미리보기 창에 등록됩니다.
  </Step>
  <Step title="송출">
    비디오 스위쳐에서 해당 채널 버튼을 누르거나 Take · Cut · T-BAR로 전환해 송출합니다.
  </Step>
</Steps>

<Figure src="/assets/gear/동영상 송출/동영상 재생.png" alt="동영상 재생 제어" caption="재생 위치·대기 상태 제어" />

미리보기 창에 등록된 동영상은 **처음 / 일시정지 / 재생** 버튼으로 재생 위치를 설정할 수 있습니다. 설정 기어에서는 프로그램 출력이 끝난 뒤의 대기 상태를 지정합니다.

| 모드 | 동작 |
| --- | --- |
| 처음 | 출력 종료 후 다시 재생하면 항상 처음부터 |
| 일시정지 | 출력이 끝나면 정지 상태로 대기 |
| 재생 | 출력이 끝나도 재생 상태로 대기 |
| 반복 | 출력 중 동영상이 반복 재생 |
