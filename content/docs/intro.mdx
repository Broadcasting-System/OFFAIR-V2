**오프에어(OFFAIR)** 는 부산소프트웨어마이스터고 방송부의 장비와 프로그램 사용법을 한곳에 모은 가이드북입니다. 처음 방송실에 들어온 부원도 이 문서만 따라가면 바로 방송을 송출할 수 있도록 정리하는 것을 목표로 합니다.

<Callout type="info" title="이렇게 읽으세요">
**시작하기 → ONAIR 시작하기** 부터 읽고, 나머지는 필요한 카테고리만 골라 보세요. 맨 아래 **방송실 장비** 는 방송실 LBS-2000 을 직접 다룰 때 보는 참고 자료입니다.
</Callout>

역대 부산소프트웨어마이스터고 방송부원들입니다.

| 기수 | 부원 |
| --- | --- |
| 2기 | 양유빈 · 박우빈 · 김병찬 · 윤동현 |
| 3기 | 김예진 · 이민준 · 박성현 · 조예설 |
| 4기 | 류승찬 · 서정현 · 조아라 · 김예빈 |
| 5기 | 김가은 · 강준석 · 박성준 · 조현우 |
| 6기 | 양유진 · 조재윤 · 육은체 · 구범준 |
