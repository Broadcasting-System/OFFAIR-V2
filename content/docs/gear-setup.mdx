## 켜기

입출력 케이블을 연결한 뒤 전원 버튼을 켜면 송출 프로그램이 **자동으로 실행**됩니다. 따로 설치하거나 실행할 것은 없습니다.

<Figure src="/assets/gear/프로그램 실행/실행.webp" alt="시스템 시작 화면" caption="전원을 켜면 자동 실행" />

시작할 때 정해 둔 시작 이미지가 잠시 나갑니다. "송출 준비중" 창에서 **취소** 를 누르면 바로 메뉴를 쓸 수 있습니다.

## 끄기

| 메뉴 | 동작 |
| --- | --- |
| 프로그램 종료 | 송출 프로그램만 끄고 윈도우로 나감. 출력은 바이패스로 정한 입력으로 바뀜 |
| 시스템 종료 | 모든 프로그램을 끄고 전원까지 끔 |

### 바이패스

바이패스는 **프로그램이 꺼진 뒤 어떤 입력을 내보낼지** 정해 두는 기능입니다. 비정상 종료 때도 적용됩니다.

<Callout type="warn">
바이패스를 정해 두지 않으면 종료 후 출력은 **무조건 1번 입력**이 됩니다.
</Callout>

## 꼭 지킬 것

<Callout type="danger" title="PC 설정을 바꾸지 마세요">
LBS-2000 은 윈도우와 하드웨어가 한 몸인 장비라 출하 때 맞춰 둔 설정 그대로 써야 합니다. 프로그램을 따로 설치하지 마세요.
</Callout>

| 항목 | 그대로 둘 값 |
| --- | --- |
| 절전 모드·HDD 절전 | 사용 안 함 |
| 화면 해상도 | 1920 × 1080 (모니터를 바꾸면 다시 맞춤) |
| 윈도우 업데이트 | 임의로 하지 않음 |
| 윈도우 비밀번호 | 걸지 않음 (꼭 걸어야 하면 반드시 기록) |

프로그램 환경 설정 비밀번호는 잃어버리면 안 됩니다.

## 뒷면 단자

<Figure src="/assets/gear/입출력 신호 연결/신호.webp" alt="신호 입출력 단자부" caption="신호 입출력 단자부" />

- **영상 입력 1~6** — HDMI 와 YPbPr. 3·4번은 HDMI 와 YPbPr 중 하나를 골라 씀
- **출력 1·2·3**
- **외부 오디오 XLR** 입력 / **PGM 오디오 XLR** 출력 (밸런스)
- **PGM 오디오** 3.5mm 출력, **Tally** 출력

### 노트북 더 연결하기

HDMI 를 USB 컨버터로 바꿔 본체 USB 단자에 꽂으면 입력 5·6번으로 **최대 2대까지** 늘릴 수 있습니다. 노트북 출력은 **1920 × 1080** 으로 맞추세요.

<Figure src="/assets/gear/입출력 신호 연결/USB.webp" alt="USB 영상 입력" caption="USB 컨버터로 입력 늘리기" />

### 오디오 연결

외부 믹서 출력 → 본체 오디오 입력(XLR L/R), 본체 PGM 출력 → 외부 믹서 입력으로 연결합니다.

<Callout type="warn" title="밸런스 연결 주의">
핀 번호와 **+ / − 극성**을 꼭 확인하세요. 밸런스와 모노를 섞어 연결하면 소리 크기가 **절반**으로 줄어듭니다.
</Callout>

## 출력 설정에서 알아 둘 것

- 출력마다 **프로그램(PGM)** 또는 **입력 1~4** 를 고릅니다. 동영상·이미지·자막을 내보내려면 반드시 **프로그램(PGM)** 이어야 합니다. PGM 으로 고른 출력은 빨간색으로 표시됩니다.
- 표준 출력 해상도는 **1920×1080 59.94i** 입니다. 입력과 출력 해상도가 다르면 흐르는 자막이 떨릴 수 있습니다.
- 입력·출력 화면 위 카메라 아이콘을 누르면 지금 화면이 **1280×720 이미지**로 저장됩니다.
