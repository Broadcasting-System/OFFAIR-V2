저장된 **영상·이미지·PPT·오디오**를 송출 화면(프로젝터)에 띄우고 원격으로 제어합니다.

<Figure src="/assets/onair/41-media-video.png" alt="미디어 송출 화면" caption="왼쪽 목록에서 파일 클릭 → 즉시 송출 · 오른쪽 미리보기 · 하단 영상 제어 바" />

## 송출 방법

왼쪽 탭에서 종류(영상 / 이미지 / PPT / 오디오)를 선택한 뒤, 목록에서 파일을 클릭하면 **즉시 송출**됩니다.

## 영상 제어

화면 하단의 제어 바에서 조작합니다.

| 항목 | 동작 |
| --- | --- |
| 재생 / 일시정지 | 영상 재생 제어 |
| 반복 | 반복 재생 ON/OFF |
| 소리 / 볼륨 | 음소거·볼륨 조절 |
| 구간 이동 | 진행바를 끌어 시킹 |
| 여백맞춤 / 꽉채움 | 화면 채움 모드 |
| 송출 끄기 | 화면 내리기 |

## 이미지 위 텍스트 (오버레이)

<Figure src="/assets/onair/43-media-overlay.png" alt="이미지 오버레이" caption="텍스트 · 표시 ON/OFF · 크기 · 색상 · 위치 패널" />

이미지를 송출하면 오버레이 패널이 나타납니다. 안내 문구 등을 이미지 위에 얹을 때 사용합니다.
