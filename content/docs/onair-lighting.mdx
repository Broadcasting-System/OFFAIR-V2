강당 무대 조명을 ONAIR 에서 조명기 하나하나(밝기·색)와 **장면** 으로 다뤄요. 조명 신호는 강당 노트북에 꽂은 USB-DMX 케이블로 나가요.

<Callout type="warn" title="먼저 연결부터">
ONAIR 로 조명을 쓰려면 조명 전원과 케이블 연결이 먼저예요. [조명 연결과 전원](/docs/onair-lighting-setup)을 보고 오세요. 연결에 필요한 젠더(XLR 3핀 수-수)를 사는 중이라, 젠더가 오기 전에는 ONAIR 로 조명을 켤 수 없어요.
</Callout>

## 조명 켜기

<Steps>
  <Step title="조명 화면">
    왼쪽 메뉴 **HALL › 조명** 을 눌러요. 위쪽 상태가 **DMX online** 이면 연결된 거예요.
  </Step>
  <Step title="조작 잠금 끄기">
    **조작 잠금** 스위치를 꺼요.
  </Step>
  <Step title="조명 올리기">
    조명 줄의 밝기를 올리거나, 위쪽 장면 하나를 눌러요.
  </Step>
</Steps>

## 화면 구성

| 칸 | 하는 일 |
| --- | --- |
| 장면 | 저장해 둔 조명 상태를 한 번에 불러요. 장면마다 바뀌는 시간(예: 2S, 즉시)이 보여요 |
| 조명 줄 | 조명 하나의 켜기·끄기, 밝기. 색이 되는 LED 는 색 버튼도 있어요 |
| 전체 줄 | 오른쪽 끝에 고정. 전체 밝기와 **암전** |
| 음악 조명 탭 | 음악 박자에 맞춰 조명을 움직여요 |

## 장면 바꾸기

- 장면 버튼을 누르면 그 장면으로 천천히 바뀌어요.
- 부장은 원하는 상태를 만든 뒤 **지금 상태 저장** 으로 새 장면을 만들 수 있어요(예: 조회, 공연, 발표).
- **암전** 은 모든 조명을 한 번에 꺼요. 다시 누르면 암전이 풀려요.

## 음악 조명

**음악 조명** 탭에서는 두 가지를 해요.

- **조명 쇼** : MR 파일을 올리면 서버가 박자와 구간을 찾아 조명 쇼를 만들어요. 음악을 트는 순간 **시작** 을 눌러요.
- **실시간 박자 따라가기** : 지금 나오는 소리의 박자에 맞춰 LED 를 움직여요.

<Callout type="info" title="눈을 지키는 규칙">
깜빡임은 1초에 3번을 넘지 않아요. 스트로브(번쩍임)는 부장이 허용한 쇼에서만 나가요. 이 규칙은 쇼 내용과 상관없이 늘 지켜요.
</Callout>

## 권한

| 할 수 있는 일 | 누가 |
| --- | --- |
| 화면 보기 | 등록된 사람 누구나 |
| 밝기·색·장면 불러오기·암전·음악 조명 틀기 | 부원 이상 |
| 장면 저장·지우기, 조명 목록·연결(현장 세팅), 스트로브 허용 | 부장 이상 |

## 말로 조작하기

CUE 도우미나 [ONAIR MCP](/docs/onair-mcp)에 "강당 조명 공연 장면으로", "전체 밝기 50으로", "암전해 줘"처럼 말해도 돼요. 암전은 위험한 조작이라 한 번 더 물어요.

## 주의할 점

- 다 쓰면 조명을 끄고, **MCC 판넬 메인 차단기** 를 내려요. 자세한 순서는 [조명 연결과 전원](/docs/onair-lighting-setup)에 있어요.
- ONAIR 로 조명을 쓰는 동안에는 Sunny 512 조명 콘솔이 아니라 ONAIR 가 조명을 쥐고 있어요. 콘솔로 돌아갈 때는 케이블을 원래대로 꽂아요.
- 무빙 라이트를 갑자기 최대 밝기로 올리지 않아요. 무대 위 사람 눈부심에 주의해요.
