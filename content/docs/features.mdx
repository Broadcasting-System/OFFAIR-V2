## 개요

방송실의 핵심 장비는 **LBS-2000 통합 방송 시스템** 입니다. 하드웨어 기반으로 설계되어 안정적이며, 여러 입력 소스를 실시간으로 전환·합성해 학교 구내 방송에 최적화되어 있습니다.

4개의 HDMI와 2개의 PbPr 입력, IP 수신, USB 카메라 등 다양한 소스를 받아들이고, 크로마키·CG·XLR 외부 오디오 입출력, 지연 없는 영상 출력, 녹화·제어까지 한 대에서 처리합니다.

## 주요 특징

| 항목 | 내용 |
| --- | --- |
| 안정성 | HW 기반 설계로 안정 동작 보증 |
| 영상 출력 | HW Mix 설계로 지연 없는 출력 |
| 입력 | 6채널 영상 입력 |
| 라우터 출력 | 서로 다른 3채널 라우터 출력 |
| 합성 출력 | 3채널 CG·단문 메시지 합성 출력 |
| 오디오 | XLR 밸런스 오디오 입·출력 |
| 배경 | 파노라마 가상 스튜디오 배경 설정 |
| 전환 효과 | 사용자 작성 가능한 다양한 전환 효과 |
| 종료 동작 | 프로그램 종료 시 지정 입력 바이패스 출력 |

<Callout type="info">
모든 영상 처리가 하드웨어에서 이뤄지기 때문에 입력에서 출력까지 **지연(latency)이 거의 없습니다.** 실시간 행사 송출에 유리합니다.
</Callout>
