## 개요

이 문서는 출하 시 기본 설정을 기준으로 설명합니다. LBS-2000은 정상 동작과 품질 시험을 거쳐 출하되므로 **별도의 드라이버나 프로그램 설치가 필요 없습니다.**

<Callout type="warn">
사용자가 임의로 프로그램을 설치하는 것은 권장하지 않습니다. 시스템 안정성에 영향을 줄 수 있습니다.
</Callout>

## 부팅 및 자동 시작

<Figure src="/assets/gear/프로그램 실행/실행.png" alt="시스템 시작 화면" caption="전원 ON 시 자동 실행" />

입출력 단자에 신호를 연결하고 전원 버튼을 켜면 시작 화면이 나타나며 송출 프로그램이 **자동으로 실행**됩니다.

## 시작·종료 이미지 송출

방송 시작과 종료 시, 지정한 시간 동안 설정된 이미지를 송출할 수 있습니다. 시작·종료 이미지는 직접 제작해 등록할 수 있습니다.

- **시작 시** — 정해진 시간(최대 999초) 동안 지정 이미지를 송출합니다. 송출 중이라도 "송출 준비중" 창에서 **취소** 를 누르면 메뉴를 제어할 수 있습니다.
- **종료 시** — 정해진 시간 동안 종료 이미지를 송출합니다. 메시지 창을 닫거나 취소하면 곧바로 종료됩니다.
- **종료 후** — 설정된 입력 채널을 출력하는 **바이패스 상태**로 전환됩니다.

## PC 환경 설정 주의사항

<Callout type="danger" title="임의 변경 금지">
LBS-2000은 윈도우와 하드웨어가 결합된 제품으로, 출하 시 최적 상태로 세팅되어 있습니다. PC 시스템 설정을 임의로 변경하지 마세요.
</Callout>

| 항목 | 권장 설정 |
| --- | --- |
| 전원 관리 (절전모드) | 사용 안 함 |
| HDD 절전모드 (고급설정) | 사용 안 함 |
| 그래픽 해상도 | 1920 × 1080 (모니터 변경 시 재설정) |
| 윈도우 업데이트 | 임의 업데이트 금지 |
| 윈도우 계정·비밀번호 | 설정하지 않음 (부득이 설정 시 반드시 메모·관리) |

<Callout type="warn" title="환경 설정 비밀번호">
메인 프로그램 환경 설정의 비밀번호는 분실하면 안 됩니다. **초기 비밀번호는 `12345`** 입니다.
</Callout>

## 실행 화면 구성

<Figure src="/assets/gear/프로그램 실행/실행화면.png" alt="프로그램 실행 화면" caption="실행 화면 구성" />

메뉴는 **전체화면 모드**로 사용하며, 각 창의 기어 아이콘을 누르면 해당 창의 세부 설정을 조정할 수 있습니다.

| 영역 | 기능 |
| --- | --- |
| 메인 메뉴 | 프로그램명·지원 등 기본 기능 |
| 영상 입력 미리보기 | 외부 입력, 대기 중인 동영상·이미지·PPT 미리보기 |
| 출력 1·2·3 화면 | 현재 출력 화면. 입력 1~4를 선택해 출력 |
| 비디오 스위쳐 | 송출 채널 선택, 효과·속도 지정, 외부 매트릭스 제어 |
| 효과·녹화 설정 | 전환 효과·T-BAR 제어, 녹화·스트리밍 상태 표시 |
| 모드 프리셋 | DDR·이미지·PPT·멀티 PIP·오디오 믹서 등 탭 제공 |

## 메인 메뉴 기능

<Figure src="/assets/gear/프로그램 실행/기능.png" alt="메인 메뉴 기능" caption="메인 메뉴 기능" />

- **지원창** — 프로그램 버전, 사용 설명, 원격 지원, 메뉴얼 자료 폴더 열기
- **녹화·스트리밍 설정** — 녹화 중 실시간 확인, 스트리밍 설정·시작·정지 제어
- **Time** — 현재 시각 표시
- **Run** — 프로그램 운용 시간(시:분:초) 표시

### 종료

| 메뉴 | 동작 |
| --- | --- |
| 프로그램 종료 | 송출 프로그램만 종료, 윈도우로 이동 (출력은 설정된 출력으로 전환) |
| 시스템 종료 | 모든 프로그램 종료 후 시스템 전원 OFF |

<Callout type="tip">
종료 시 설정 옵션에 따라 **바이패스 모드** 또는 **방송 종료 이미지** 를 일정 시간 송출하도록 할 수 있습니다.
</Callout>
