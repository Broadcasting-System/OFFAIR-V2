화면 최상단의 상태 표시줄은 방송 시스템의 현재 상태를 한눈에 보여 줍니다. 항목은 왼쪽에서 오른쪽 순서로 배치되어 있습니다.

<Figure src="/assets/software/상태표시.png" alt="시스템 상태 표시줄" caption="상단 상태 표시줄 — 왼쪽에서 오른쪽 순" />

## 표시 항목

| 항목 | 설명 | 색상 |
| --- | --- | --- |
| 기본 정보 | 운용 프로그램명과 학교명 | — |
| 리모트 컨트롤러 | 연결된 4개 컨트롤러의 작동 여부 | 사용 시 녹색 |
| ON AIR | 현재 방송 상태 | 방송 중 녹색 |
| PC | PC를 통한 송출 여부 | 송출 중 푸른색 |

<Callout type="tip">
리모트 컨트롤러 표시등 4개가 모두 녹색이면 모든 컨트롤러가 정상 연결된 상태입니다. 하나라도 꺼져 있으면 해당 컨트롤러의 연결을 확인하세요.
</Callout>
