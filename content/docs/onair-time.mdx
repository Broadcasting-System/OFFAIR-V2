학교 종(시보)을 **그룹·요일별 시간표** 로 만들고, **적용하기** 로 서버에 보내요. 메뉴는 **SETUP › 시보** 예요.

<Figure src="/assets/onair/11-time-list.webp" alt="시보 설정 화면" caption="그룹, 요일, 시보 목록, 적용하기" />

## 화면 구성

| 영역 | 설명 |
| --- | --- |
| 그룹 (GROUP 1~5) | 시간표를 5개까지 따로 둬요 (예: 평상시 / 시험기간 / 행사용). 이름을 바꿀 수 있어요. 지금 울리는 그룹이 표시돼요 |
| 요일 | 월·화·수·목·금 + **P(특별)** |
| 시보 목록 | 그 요일의 시보 (시각 / 이름 / 장소) |
| 적용하기 | 고친 내용을 서버에 보내요. 안 보낸 변경 수가 같이 보여요 |
| 특별 시간표로 울리기 | P 시간표를 매일 울리는 스위치 |

화면 위쪽에 지금 울리는 그룹과 다음 종까지 남은 시간이 보여요.

## 시보 추가하기

<Steps>
  <Step title="그룹·요일 고르기">
    고칠 **그룹과 요일** 을 골라요.
  </Step>
  <Step title="편집 창 열기">
    시보 추가를 누르면 편집 창이 열려요.
  </Step>
  <Step title="내용 채우기">
    아래 항목을 채우고 **추가**(고칠 때는 **저장**)를 눌러요.
  </Step>
  <Step title="적용하기">
    **적용하기** 를 눌러야 서버에 들어가요. 추가·저장만 하면 화면에서만 바뀐 거예요.
  </Step>
</Steps>

<Figure src="/assets/onair/12-time-editor.webp" alt="시보 편집 창" caption="시보 편집 창. 이름, 장소, 시간, 음악" />

| 항목 | 설명 |
| --- | --- |
| 시보 이름 | 예: `1교시 시작` |
| 울릴 시간 | 울릴 시각 |
| 울리는 요일 | 같은 시보를 여러 요일에 한 번에 넣을 수 있어요 |
| 울리는 곳 | **PC**(서버 PC 가 음원을 스피커로) 또는 **장비**(방송실 시보 장비가 스스로) |
| 장소 | 학년 버튼(1·2·3학년)이나 **학교 전체**, 또는 교실·특별실을 하나씩 |
| 시보 음악 | **파일** 에 올려 둔 음원. 미리 듣기로 확인해요 |
| 송출 볼륨 | 100 이 기본 크기예요 |

<Callout type="info" title="울리는 곳이 장비일 때">
장비로 정한 시보는 적용하기 때 장비에 보내요. 장비에 못 보냈으면 서버 PC 가 대신 울려요. 화면에 **장비 못 보냄 · PC로 울려요** 가 보이면 이 상태예요. 대신 울리려면 그 시보에 음원과 장소가 들어 있어야 해요.
</Callout>

## 복사 · 비우기

| 기능 | 설명 |
| --- | --- |
| 다른 요일에 복사 | 지금 요일 시보를 고른 요일에 통째로 복사해요. 그 요일에 있던 시보는 지워지고 바뀌어요 |
| 이 요일 비우기 | 지금 요일 시보를 모두 지워요. 적용하기를 눌러야 서버에도 반영돼요 |

## 적용하기 · 그룹 바꾸기

- 지금 울리는 그룹을 고쳤으면 **적용하기** 를 눌러요.
- 다른 그룹을 고쳤으면 **저장만** 으로 서버에 저장만 하거나, **이 시간표로 울리기** 로 그 그룹을 지금부터 울리는 그룹으로 바꿔요.
- 울리는 그룹을 바꾸면 특별 시간표로 울리기는 꺼져요.

## 특별(P) 시간표

**P 는 요일과 상관없이 매일 울릴 특별 시간표** 예요. 시험 기간이나 행사 주간에 써요.

<Figure src="/assets/onair/13-time-special.webp" alt="특별 시간표" caption="특별 시간표로 울리기 스위치. 켜지면 빨갛게 바뀌어요" />

- **켜면** P 시보가 주말까지 매일 울리고, 평일(월~금) 시보는 쉬어요.
- **끄면** 평일 시간표로 돌아가요.
- P 시보가 하나도 없으면 켤 수 없어요.

## 종이 먼저예요

시보는 **제 시각에 울리거나, 못 울리면 아예 건너뛰어요.** 늦게 울리지 않아요. 그래서 종 직전에는 다른 방송이 비켜요.

- TTS·음원 방송은 종까지 다 끝낼 수 없으면 시작하지 않아요.
- 마이크 방송과 강당 교실 중계는 종 약 20초 전에 저절로 끝나요.
- 선생님 예약 안내 방송은 종이 다 울린 뒤로 미뤄져요.

## 말로 만들기

CUE 도우미나 [ONAIR MCP](/docs/onair-mcp)에 **시간표 사진** 을 주고 "이걸로 시보 만들어 줘"라고 하면 시보 표를 만들어 보여 줘요. 표를 확인하고 실행하면 들어가요. "금요일 종례 끝종 빼 줘"처럼 몇 개만 고칠 수도 있어요.

<Callout type="warn" title="적용하기를 잊지 마세요">
편집만 하고 **적용하기** 를 누르지 않으면 종이 바뀌지 않아요. 적용한 뒤 화면 위쪽의 다음 종을 한 번 확인해요.
</Callout>

## 부장 탭

부장 이상에게는 **예약 현황** 과 **야간 절전** 탭이 더 보여요.

- **예약 현황** : 서버에 걸린 시보와 예약 송출을 시각 순서로 봐요.
- **야간 절전** : 밤에 켜진 교실 스피커를 끄고 송출 화면을 대기 화면으로 돌리는 설정이에요.
