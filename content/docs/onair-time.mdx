학교 종(시보)을 **그룹·요일별 시간표**로 등록하고 서버에 전송합니다.

<Figure src="/assets/onair/11-time-list.png" alt="시보 설정 화면" caption="① GROUP 탭  ② 요일(M T W T F P)  ③ 시보 목록  ④ 오른쪽 버튼 영역" />

## 화면 구성

| 영역 | 설명 |
| --- | --- |
| GROUP 1~5 탭 | 시간표를 5개 그룹으로 관리 (예: 평상시 / 시험기간 / 행사용) |
| 요일 선택 | 월·화·수·목·금 + **P(특별)** |
| 시보 목록 | 등록된 시보 카드 (라벨 / 시간 / 선택한 장소 요약) |
| 시보 추가·전송 | 시보를 추가하고 서버로 전송하는 버튼 |

## 시보 추가하기

<Steps>
  <Step title="그룹·요일 선택">
    상단에서 편집할 **그룹과 요일**을 고릅니다.
  </Step>
  <Step title="편집 패널 열기">
    **시보 추가** 를 클릭하면 편집 패널이 열립니다.
  </Step>
  <Step title="내용 입력">
    아래 항목을 채웁니다. 라벨·스피커·시간·음악을 지정합니다.
  </Step>
  <Step title="저장">
    **저장** 하면 목록에 카드가 추가됩니다. (카드에는 시간과 선택한 장소가 요약 표시)
  </Step>
</Steps>

<Figure src="/assets/onair/12-time-editor.png" alt="시보 편집 패널" caption="라벨 · 빠른 선택 · 스피커 그리드 · 시보 시간 · 시보 음악" />

| 항목 | 설명 |
| --- | --- |
| 라벨 | 시보 이름 (예: `1교시 시작`) |
| 빠른 선택 | `1학년 / 2학년 / 3학년 / 전 학년 / 학교 전체` 로 스피커 일괄 선택 (다시 누르면 해제) |
| 개별 스피커 | 교실·특별실을 직접 켜고 끄기 |
| 시보 시간 | 울릴 시각 |
| 시보 음악 | 미리 업로드한 음원 선택 (파일 관리에서 등록) |

## 복사 · 초기화 · 전송

| 기능 | 설명 |
| --- | --- |
| 요일 시보 복사 → 붙여넣기 | 한 요일의 시보를 통째로 다른 요일에 복제 |
| 초기화 | 현재 요일의 시보 전부 삭제 |
| 시보 전송 | 편집 내용을 서버에 등록 (전송 완료 시 우측 상단 알림) |

## 특별(P) 모드

**P는 요일과 상관없이 매일 반복할 특별 시간표** 입니다.

<Figure src="/assets/onair/13-time-special.png" alt="특별(P) 모드" caption="오른쪽 버튼 영역의 '특별(P) 모드' 버튼 — 켜지면 보라색" />

- **ON** → P 시간표가 매일 동작하고, 평일(월~금) 시보는 잠시 중단됩니다.
- **OFF** → 평일 시간표로 복귀합니다.
- 버튼을 누르면 **즉시 서버에 반영**됩니다.

<Callout type="warn" title="전송을 잊지 마세요">
반드시 **`시보 전송`** 을 눌러야 편집 내용이 적용됩니다. 편집만 하고 전송하지 않으면 울리지 않습니다.
</Callout>
