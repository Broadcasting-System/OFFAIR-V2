외부 강사나 다른 동아리 발표자가 **자기 노트북 화면** 을 송출 채널로 보내요. 발표자는 계정이 없어도 돼요. 방송부가 만든 **공유 코드** 만 있으면 어디서든 요청할 수 있고, 방송부가 요청마다 미리보기를 보고 **허용** 해야 화면이 나가요.

## 공유 코드 받기

<Steps>
  <Step title="코드 만들기">
    컨트롤 화면 **LIVE › 송출** 의 송출 화면에서 **외부 화면** 칸을 열고 코드를 만들어요. 코드는 10분 동안 쓸 수 있어요.
  </Step>
  <Step title="발표자에게 알려 주기">
    발표자에게 **share.bssmcast.com** 주소와 코드를 알려 줘요.
  </Step>
  <Step title="발표자가 요청">
    발표자는 그 주소에서 코드와 이름을 넣고 화면 공유를 요청해요. 소리를 같이 보낼지는 발표자가 브라우저 공유 창에서 골라요.
  </Step>
</Steps>

<Figure src="/assets/onair/share-presenter.webp" alt="발표자 화면" caption="발표자 화면. 공유 코드와 이름을 넣고 요청" />

<Callout type="note">
휴대폰은 화면 공유가 안 돼요. 발표자는 노트북으로 들어와야 해요.
</Callout>

## 요청 허용하기

요청이 오면 외부 화면 칸에 요청 카드가 생겨요. 탭에 기다리는 요청 수가 보여요.

1. 카드의 **미리보기 사진** 으로 발표자 화면을 확인해요.
2. 내보낼 **채널** 을 골라요.
3. **허용** 을 누르면 그 채널에 발표자 화면이 나가요. 이상하면 **거절** 해요.

- 같은 채널에 다른 사람을 새로 허용하면 앞 사람은 끝나요.
- 기다리는 요청은 30분이 지나면 사라져요.

## 끝내기

| 버튼 | 하는 일 |
| --- | --- |
| 끊기 | 송출 중인 발표자 화면을 끊어요 |
| 받기 끝내기 | 코드를 닫아요. 공유 중인 화면도 끊겨요 |

발표가 끝나면 **받기 끝내기** 까지 눌러 코드를 닫아요.

<Callout type="warn">
허용 전에 미리보기를 꼭 봐요. 개인 메신저·메일 창이 열린 채 공유를 요청하는 경우가 있어요. 그대로 허용하면 송출 화면에 그대로 나가요.
</Callout>

## 권한

부원 이상이 코드 만들기·허용·끊기를 할 수 있어요. CUE 도우미나 [ONAIR MCP](/docs/onair-mcp)에 "공유 요청 CH2 로 허용해 줘"라고 해도 돼요.
