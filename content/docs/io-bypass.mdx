## 개요

<Figure src="/assets/gear/바이패스 설정/바이패스.png" alt="바이패스 설정" caption="시작·종료 시 출력 지정" />

바이패스는 **프로그램 시작·종료·시스템 종료** 시점에 어떤 출력을 내보낼지 지정하는 기능입니다.

| 시점 | 동작 |
| --- | --- |
| 프로그램 시작 시 | 정해진 시간 동안 지정 이미지를 송출 |
| 프로그램 / 시스템 종료 시 | 일정 시간 동안 지정 이미지를 송출 |
| 프로그램 종료 후 | 지정한 입력을 바이패스 출력으로 내보냄 (비정상 종료 시에도 적용) |

<Callout type="warn">
바이패스가 설정되어 있지 않으면, 종료 후 출력은 **무조건 1번 입력**으로 지정됩니다. 원하는 입력이 있다면 미리 지정해 두세요.
</Callout>
