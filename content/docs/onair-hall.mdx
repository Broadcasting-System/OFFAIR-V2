강당 음향 콘솔(Soundcraft Si Expression)을 방송실이나 내 기기에서 ONAIR 로 조작해요. 콘솔 옆 **강당 노트북**이 ONAIR 와 콘솔 사이를 이어 줘요. 콘솔에서 직접 만져도 되고, ONAIR 에서 바꿔도 돼요. 둘은 같은 값을 보고 있어요.

<Figure src="/assets/onair/hall-mixer.webp" alt="컨트롤 › 오디오" caption="HALL › 오디오. 채널 페이더와 뮤트, 위쪽 씬 버튼" />

## 콘솔 연결 확인

<Steps>
  <Step title="오디오 화면 열기">
    왼쪽 메뉴 **HALL › 오디오** 를 눌러요. 위쪽에서 공간(강당·다목적홀)을 골라요.
  </Step>
  <Step title="연결 표시 보기">
    **믹서 연결됨** 이 보이면 바로 쓸 수 있어요. **믹서 연결 안 됨** 이면 강당 노트북이 켜져 있는지 먼저 봐요.
  </Step>
  <Step title="조작 잠금 풀기">
    화면은 열 때마다 **조작 잠금** 이 켜진 채로 시작해요. 실수로 페이더를 건드리지 않게 하려는 거예요. 조작할 때만 스위치를 꺼요.
  </Step>
</Steps>

<Callout type="info">
강당 노트북은 켜고 로그인하면 **ONAIR Bridge** 창이 저절로 떠요. 이 창이 떠 있어야 ONAIR 가 콘솔에 닿아요. 창을 닫지 마세요.
</Callout>

## 강당 채널

강당 콘솔은 21채널을 ONAIR 에서 다뤄요. 화면 왼쪽부터 이 순서로 보여요.

| 이름 | 무엇 |
| --- | --- |
| MIC 1~15 | 마이크 입력 15개 |
| 예비 PC | PC 소리 |
| 무선 1~4 | 무선 마이크 4개 |
| CDP | CD 플레이어 |

<Callout type="note">
채널 이름은 부장이 **현장 세팅** 에서 바꿀 수 있어요. 화면에 보이는 이름이 위 표와 다르면 화면 이름을 따라요.
</Callout>

## 채널 조작

- **페이더** : 위아래로 끌어 크기를 바꿔요. 콘솔의 모터 페이더도 같이 움직여요.
- **뮤트** : 채널 아래 버튼으로 끄고 켜요.
- **게인 링** : 채널 위 동그란 링을 좌우로 끌면 입력 크기(게인)가 바뀌어요.
- **채널 이름표(SEL)** : 누르면 위쪽 **채널 처리** 에 그 채널의 게인·EQ·컴프·FX 가 열려요. 자세한 건 [콘솔 세부 조절](/docs/onair-hall-processing)을 봐요.

<Callout type="tip">
채널마다 **MAX** 가 정해져 있을 수 있어요. 하울링을 막으려고 그 위로는 못 올리게 해 둔 거예요.
</Callout>

## 씬

콘솔에 저장해 둔 장면(씬)을 버튼 하나로 불러요. 씬을 바꾸면 **콘솔 전체** 설정이 그 씬으로 바뀌어요.

- 씬 버튼을 누르면 "씬을 바꿀까요?" 하고 한 번 더 물어요.
- **확인 필요** 표시가 있는 씬(비상방송·행사용 등)은 특히 조심해요.
- 행사 중에 씬을 바꾸면 마이크 크기가 한꺼번에 바뀌어요. 사회자와 맞춘 뒤에 바꿔요.

## 권한

| 할 수 있는 일 | 누가 |
| --- | --- |
| 화면 보기 | 등록된 사람 누구나 |
| 페이더·뮤트·게인·씬·채널 처리 | 부원 이상 |
| 현장 세팅(연결·채널 목록·씬 목록·주소 연결) | 부장 이상 |

<Callout type="warn" title="씬 전환만 쓰는 공간">
현장 세팅에서 **씬 전환만** 으로 정한 공간은 채널을 ONAIR 에서 못 움직여요. 그 공간은 콘솔에서 직접 조작해요.
</Callout>

## 말로 조작하기

CUE 도우미나 [ONAIR MCP](/docs/onair-mcp)에 "강당 MIC 3 조금 올려 줘", "무선 2 뮤트해 줘"처럼 말해도 돼요. 바로 바뀌지 않고, 무엇을 할지 보여 준 뒤 확인을 받아요.
