방송에 쓸 **이미지·동영상·음원·프리젠테이션**을 업로드하고 관리합니다.

<Figure src="/assets/onair/21-files.webp" alt="파일 관리 화면" caption="종류별(이미지 / 동영상 / 음원 / 프리젠테이션) 목록" />

## 업로드

각 영역의 **파일 추가** 버튼을 누르거나 **드래그 & 드롭**으로 업로드합니다.

<Callout type="info">
동영상은 업로드 시 **자동으로 송출용으로 변환**됩니다. 이미 표준 형식이면 몇 초, 아니면 조금 더 걸립니다.
</Callout>

## 파일 다루기

<Figure src="/assets/onair/22-files-context.webp" alt="파일 우클릭 메뉴" caption="파일 우클릭 → 미리보기 / 이름 수정 / 삭제" />

- **이름 수정** : 보기 좋은 이름으로 변경할 수 있습니다. 표시 이름만 바뀌므로 시보·송출이 깨지지 않습니다.
- **삭제 / 미리보기** : 우클릭 메뉴에서 바로 처리합니다.

<Callout type="tip">
**음원은 여기서 올려둬야** [시보 설정](/docs/onair-time)의 '시보 음악'에서 선택할 수 있습니다.
</Callout>
