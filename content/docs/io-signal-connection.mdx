본체의 전면·후면 단자 구성과 영상·오디오 신호를 연결하는 방법을 정리합니다.

## 전면부 (Front)

<Figure src="/assets/gear/입출력 신호 연결/Front.png" alt="본체 전면부" caption="전면부 구성" />

| 번호 | 명칭 | 설명 |
| --- | --- | --- |
| 1 | Power 버튼 | 시스템 동작을 켜고 끄는 버튼 |
| 2 | Reset 버튼 | PC를 강제로 재부팅·리셋 |
| 3 | USB 2.0 | 전면 USB 2.0 인터페이스 |
| 4 | ODD | CD-RW / DVD Multi R/W |

## 후면부 (Rear)

<Figure src="/assets/gear/입출력 신호 연결/Rear.png" alt="본체 후면부" caption="후면부 구성" />

| 번호 | 명칭 | 설명 |
| --- | --- | --- |
| 1 | AC 전원 | AC 220V 60Hz 입력 |
| 2 | 전원 스위치 | AC 공급 전원 ON/OFF |
| 3 | 기본 메뉴 HDMI | 듀얼 모니터용 연결 단자 |
| 4 | 확장 모니터 HDMI | 미사용 |
| 5 | USB | 키보드·마우스 연결 |

## 신호 입출력 단자

<Figure src="/assets/gear/입출력 신호 연결/신호.png" alt="신호 입출력 단자부" caption="신호 입출력 단자부" />

- **HDMI 영상 입력** 단자
- **YPbPr 영상 입력** 단자 — 3·4번은 HDMI 3·4번과 겸용으로 선택 (`YPbPr 3 ↔ HDMI 3`, `YPbPr 4 ↔ HDMI 4`)
- **출력 1·2·3** 단자
- **외부 Audio XLR** 밸런스 입력
- **외부 PGM Audio XLR** 밸런스 출력
- **Tally** 출력 (Open/Closed 접점)
- **PGM 오디오** 출력 (3.5mm)

## 기본 연결 순서

<Figure src="/assets/gear/입출력 신호 연결/기본 신호 연결.png" alt="기본 신호 연결" caption="기본 신호 연결도" />

<Steps>
  <Step title="전원 연결">
    AC 220V 전원 플러그를 삽입합니다.
  </Step>
  <Step title="입력 장치 연결">
    키보드와 마우스를 USB 단자에 연결합니다.
  </Step>
  <Step title="모니터 연결">
    HDMI 출력 케이블을 차례대로 연결합니다.
  </Step>
</Steps>

영상·음성 신호는 연결 도면을 참고하여 연결합니다.

## 영상 입력 연결

<Figure src="/assets/gear/입출력 신호 연결/영상 신호.png" alt="영상 신호 연결" caption="영상 입력·출력 신호 연결" />

외부 비디오 입력은 **1~6번 채널**까지 사용할 수 있습니다. 단, HDMI 3·4번과 YPbPr 5·6번 입력은 서로 겸용이므로 둘 중 하나를 선택해 사용합니다.

## USB 영상 입력 확장

<Figure src="/assets/gear/입출력 신호 연결/USB.png" alt="USB 영상 입력" caption="USB 컨버터를 통한 영상 입력 확장" />

노트북 등의 추가 HDMI 신호를 USB 컨버터로 변환해 본체 USB 단자에 연결하면, 입력 5·6번 채널로 **최대 2개까지** 확장할 수 있습니다.

<Steps>
  <Step title="노트북 → 컨버터 (HDMI)">
    노트북과 컨버터 사이를 HDMI 케이블로 연결합니다.
  </Step>
  <Step title="컨버터 → 본체 (USB 3.0)">
    컨버터의 USB 3.0 출력을 본체 후면 USB 단자에 연결합니다.
  </Step>
</Steps>

USB 카메라(웹캠)를 연결할 때는 카메라가 지원하는 해상도·프레임을 확인해 용도에 맞게 설치합니다.

<Callout type="tip">
노트북 출력 해상도는 **1920 × 1080** 을 권장합니다.
</Callout>

## 오디오 연결

<Figure src="/assets/gear/입출력 신호 연결/오디오 신호.png" alt="오디오 신호 연결" caption="오디오 신호 입출력 연결" />

<Steps>
  <Step title="외부 믹서 → 본체 (입력)">
    외부 오디오 믹서의 출력을 본체의 오디오 입력 L/R XLR 단자에 연결합니다.
  </Step>
  <Step title="본체 → 외부 믹서 (출력)">
    본체의 프로그램 오디오 출력을 외부 오디오 믹서 입력에 연결합니다.
  </Step>
</Steps>

<Callout type="warn" title="밸런스 연결 주의">
- 밸런스 입출력이므로 핀 번호와 **+ / − 극성을 반드시 확인**하세요.
- 밸런스 ↔ 모노 방식을 상호 연결하면 신호 이득이 **1/2로 저하**됩니다.
</Callout>
