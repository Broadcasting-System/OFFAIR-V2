선생님은 학교 구글 계정(@bssm.hs.kr)으로 **teacher.bssmcast.com** 에 들어와 방송부에 일을 부탁해요. 방송부는 컨트롤 화면 **LIVE › 요청함** 에서 받아 수락·거절·완료해요.

## 선생님이 요청하는 법

<Figure src="/assets/onair/teacher-page.webp" alt="선생님 화면" caption="선생님 화면. 위쪽은 바로 방송, 아래는 부탁할 일 고르기" />

처음 들어온 선생님은 이름·담당·업무를 적어 등록 신청을 해요. 부장이 등급을 골라 승인하면 그때부터 쓸 수 있어요.

| 등급 | 할 수 있는 요청 |
| --- | --- |
| 일반 교사 | 반·학년 안내 방송, 영상·자료 송출 |
| 부장·학년부 | 위에 더해 학교 전체 안내 방송, 행사 지원 |
| 교무·관리자 | 위에 더해 시보 변경 |

### 선생님 바로 방송

승인된 선생님은 홈 맨 위에서 방송부를 거치지 않고 바로 방송할 수 있어요.

- **마이크** : 큰 ONAIR 버튼으로 켜고 꺼요. 한 번에 15분까지예요.
- **글** : 500자까지 적으면 TTS 로 읽어 줘요.
- 다른 방송이나 시보가 나가는 중이면 버튼이 꺼지고 까닭이 한 줄 보여요.

## 부원이 확인·처리하는 법

<Figure src="/assets/onair/teacher-requests.webp" alt="컨트롤 › 요청함" caption="LIVE › 요청함. 요청을 골라 수락·거절" />

새 요청이 오면 디스코드로 알림이 오고, 사이드바 **요청함** 에 빨간 숫자가 떠요.

| 요청 종류 | 수락하면 |
| --- | --- |
| 안내 방송 · 글 읽어 주기 | 그 시각에 TTS 방송이 **자동 예약** 돼요 |
| 안내 방송 · 방송부가 읽기 | 자동 없음. 방송부가 직접 방송하고 **완료** |
| 영상·자료 송출 | 파일은 파일 관리에 들어가고, 고른 채널에 그 시각 송출이 **자동 예약** 돼요. 유튜브 링크도 예약 송출돼요 |
| 행사 지원 · 시보 변경 | 자동 없음. 방송부가 준비하고 **완료** |

- 요청마다 선생님과 한마디(댓글)를 주고받을 수 있어요.
- 거절하거나 선생님이 취소하면 걸려 있던 예약도 지워져요.
- 선생님 파일은 요청함에서 미리 보고 내려받을 수 있어요.

<Callout type="info" title="종이 먼저예요">
예약된 안내 방송이 시보와 겹치면 내보내지 않고 **종이 다 울린 바로 뒤로** 미뤄요. 선생님 요청에 "종이 울려서 ○시 ○분에 내보냈어요" 한마디가 붙어요. 세 번 미뤄도 겹치면 보내지 못했다고 알려요.
</Callout>

## 권한

| 할 수 있는 일 | 누가 |
| --- | --- |
| 요청 보기·수락·거절·완료·댓글 | 부원 이상 |
| 선생님 승인·등급 바꾸기·내보내기 | 부장 이상 |

CUE 도우미나 [ONAIR MCP](/docs/onair-mcp)에 "선생님 요청 수락해 줘"라고 해도 돼요. 선생님 계정 승인은 화면에서 해요.
