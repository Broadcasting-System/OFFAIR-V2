강당 콘솔 소리를 깨끗하게 녹음하려면 콘솔의 **녹음 버스** 를 USB 오디오 인터페이스 **M-Track Duo** 로 강당 노트북에 넣어요. 이 입력은 [녹음·녹화](/docs/onair-recording)와 [강당 소리 교실 중계](/docs/onair-hall-relay)가 같이 써요.

```
강당 콘솔 녹음 버스 (마이크 버스, 음악 버스)
   → XLR 케이블 2개
   → M-Track Duo 입력 1 · 입력 2
   → USB
   → 강당 노트북 (ONAIR Bridge)
   → ONAIR 서버
```

## 입력 정하기

| M-Track 입력 | 들어가는 소리 | ONAIR 통로 이름 |
| --- | --- | --- |
| 입력 1 | 마이크 버스 (사회자·무선·유선 마이크) | 마이크 |
| 입력 2 | 음악 버스 (PC·CD 등 재생 소리) | 음악 |

녹음은 48kHz 2채널 WAV 하나로 저장돼요. 입력 1 이 통로 1(마이크), 입력 2 가 통로 2(음악)예요.

## 연결 순서

<Steps>
  <Step title="콘솔 출력에서 케이블 잇기">
    콘솔 녹음 버스 출력 두 곳과 M-Track **입력 1(마이크)**, **입력 2(음악)** 를 XLR 케이블로 이어요. 케이블은 자르지 않아요.
  </Step>
  <Step title="팬텀 전원 끄기">
    M-Track 의 **PHANTOM POWER** 스위치는 꺼 둬요. 콘솔 출력에는 팬텀 전원이 필요 없어요.
  </Step>
  <Step title="노트북에 꽂기">
    M-Track 을 USB 로 강당 노트북에 꽂아요. 윈도우 소리 설정의 입력 장치에 **Line (USB AUDIO CODEC)** 이 보이면 된 거예요.
  </Step>
  <Step title="ONAIR 에서 미터 보기">
    **HALL › 녹음·녹화** 에서 소리를 **강당 콘솔** 로 고르고, 마이크에 대고 말해 봐요. 미터가 움직이면 끝이에요.
  </Step>
</Steps>

<Callout type="info" title="입력 장치 이름">
ONAIR 녹음 설정의 입력 장치는 **Line (USB AUDIO CODEC)** 으로 맞춰 뒀어요. 부장이 설정했으니 부원은 건드리지 않아요. 드라이버를 새로 깔면 이름이 바뀔 수 있어요. 그때는 부장에게 알려요.
</Callout>

## 크기 맞추기

- 리허설 때 녹음 화면 미터를 보면서 M-Track 의 **GAIN** 손잡이로 맞춰요.
- 가장 큰 소리(박수·합창)에서 미터가 **-12 ~ -6 dBFS** 쯤이면 좋아요.
- 미터 끝이 빨개지면(0dB) 소리가 찢어져요. 녹음 중 몇 번 찢어졌는지 화면에 떠요.
- GAIN 을 다 내려도 빨개지면 콘솔에서 녹음 버스 마스터를 조금 내려요.

<Callout type="tip">
녹음 버스는 페이더 뒤(Post-fader) 소리예요. 음향 담당이 콘솔에서 마이크를 내리면 녹음에서도 작아져요. 그날 객석에 들린 대로 담긴다고 생각하면 돼요.
</Callout>

## 하면 안 되는 것

- 팬텀 전원(PHANTOM POWER)을 켜지 않아요.
- 녹음 중에 M-Track USB 를 뽑지 않아요. 녹음이 끊기고 교실 중계도 멈춰요.
- 다른 프로그램(녹음기·Zoom 등)으로 M-Track 을 열지 않아요. ONAIR 가 입력을 못 열 수 있어요.

## 안 될 때

| 증상 | 확인 |
| --- | --- |
| 미터가 안 움직임 | M-Track USB, 윈도우 소리 설정의 입력 장치 사용 허용, 콘솔 녹음 버스 마스터·출력 |
| 오디오 입력 장치를 찾을 수 없습니다 | 입력 장치 이름이 바뀐 것. 부장이 녹음 설정에서 다시 골라요 |
| 오디오 입력을 열지 못했습니다 | 다른 프로그램이 M-Track 을 쓰고 있어요. 닫아요 |
| 한쪽 통로만 소리 남 | 입력 1·2 케이블 중 하나가 빠졌거나 콘솔 버스 하나에 소리가 안 보내져요 |
