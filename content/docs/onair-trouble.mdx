먼저 화면에 뜬 **메시지를 그대로 읽어요.** ONAIR 는 대부분 까닭을 한 줄로 알려 줘요. 그래도 모르겠으면 CUE 도우미에게 메시지를 붙여 물어봐요.

## ONAIR 에 안 들어가질 때

| 증상 | 확인 |
| --- | --- |
| 로그인 창에서 막힘 | 부원으로 등록된 메일(개인 메일이나 @bssmcast.com)로 로그인했는지 |
| 보기만 됨 | 아직 **승인 대기** 거나 졸업 처리됐어요. 부장에게 물어봐요 |
| 화면이 아예 안 열림 | 서버 PC 가 꺼졌거나 다시 켜지는 중이에요. 잠시 뒤 다시 열고, 계속 안 되면 부장에게 알려요 |

## 소리가 안 날 때

| 증상 | 확인 |
| --- | --- |
| 다른 방송이 진행 중이에요 | 한 번에 한 방송만 돼요. 지금 방송(마이크·TTS·선생님 방송·교실 중계)이 끝나길 기다려요 |
| ○○ 종이 곧 울려요 | 종이 먼저예요. 종이 끝난 뒤 다시 해요 |
| 방송은 됐는데 교실에서 안 들림 | 대상 스피커를 제대로 골랐는지, 그 교실 스피커 볼륨 |
| 마이크 방송이 갑자기 끝남 | [마이크 방송](/docs/onair-mic)의 저절로 끝나는 까닭 표를 봐요 |

## 송출 화면이 안 뜰 때

- 송출 화면에서 그 채널이 **대기** 인지 봐요. 파일을 다시 눌러 송출해요.
- 파일은 먼저 **파일** 메뉴에 올라가 있어야 해요. 영상은 올린 뒤 변환이 끝나야 고를 수 있어요.
- 프로젝터·TV 쪽 송출 PC 가 켜져 있는지 봐요.

## 시보가 안 울릴 때

| 확인 | 설명 |
| --- | --- |
| 적용하기 | 고친 뒤 **적용하기** 를 눌렀는지. 저장만 하면 안 울려요 |
| 울리는 그룹 | 지금 울리는 그룹이 내가 고친 그룹인지 |
| 특별 시간표 | **특별 시간표로 울리기** 가 켜져 있으면 평일 시보 대신 특별(P) 시보가 울려요 |
| 음원·스피커 | 시보에 음원과 스피커가 들어 있는지 |
| 서버 PC | 꺼져 있었거나 그 시각에 재시작 중이었는지 |

시보 화면 옆에 **장비 못 보냄 · PC로 울려요** 가 보이면 장비 대신 서버 PC 가 울리고 있다는 뜻이에요. 종은 울려요.

## 강당 장비가 안 될 때

| 증상 | 확인 |
| --- | --- |
| 믹서 연결 안 됨 | 강당 노트북 전원, 로그인, **ONAIR Bridge** 창 |
| 페이더는 되는데 손잡이가 안 따라옴 | 주소 연결 문제예요. 부장에게 알려요 ([콘솔 세부 조절](/docs/onair-hall-processing)) |
| 조명 DMX offline | [조명 연결과 전원](/docs/onair-lighting-setup)의 안 될 때 표 |
| 녹음 미터가 안 움직임 | [강당 녹음 장비 연결](/docs/onair-recording-setup)의 안 될 때 표 |
| 교실 중계가 안 켜짐 | [강당 소리 교실 중계](/docs/onair-hall-relay)의 안 될 때 표 |

## 그래도 안 되면

1. 무엇을 하다가, 몇 시에, 어떤 메시지가 떴는지 적어요.
2. 부장에게 알려요. 부장은 **ADMIN › 로그** 에서 그 시각 기록을 볼 수 있어요.
