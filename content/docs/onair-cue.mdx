**CUE** 는 ONAIR 컨트롤 화면 안에 있는 도우미예요. 말로 물어보면 답하고, 말로 시키면 확인 카드를 띄운 뒤 실제로 조작해요.

<Figure src="/assets/onair/cue-panel.webp" alt="CUE 창" caption="CUE 창. 메뉴의 CUE 단추나 ⌘K 로 열어요" />

## CUE 가 하는 일

| 하는 일 | 예 |
| --- | --- |
| 상태 묻기 | "지금 송출 뭐 나가?", "다음 시보 언제야?" |
| 방법 묻기 | "현수막 점수보드 어떻게 써?" (이 가이드북을 찾아 읽고 답해요) |
| 조작 맡기기 | "1학년 스피커 켜 줘", "강당 공연 씬으로 바꿔 줘" |
| 사진·파일로 맡기기 | 시간표 사진을 올리고 "이걸로 시보 만들어 줘" |
| 화면 안내 | "시보 추가하는 법 보여 줘" (화면에서 단계별로 짚어 줘요) |

## 물어보는 법

<Steps>
  <Step title="열기">
    왼쪽 메뉴의 **CUE** 단추를 누르거나 <Kbd>⌘</Kbd> <Kbd>K</Kbd> 를 눌러요.
  </Step>
  <Step title="말하기">
    하고 싶은 걸 그냥 말로 적어요. 어느 그룹·채널·스피커인지 빠지면 CUE 가 선택지를 보여 주며 물어요.
  </Step>
  <Step title="확인 카드">
    조작은 **확인 카드** 로 나와요. 내용을 읽고 맞으면 **확인** 을 눌러요. 누르기 전에는 아무것도 안 바뀌어요.
  </Step>
</Steps>

- 확인 카드는 **만든 사람만**, **10분 안에**, **한 번만** 누를 수 있어요.
- 시보 카드는 표로 보여 줘요. 표를 고친 뒤 확인할 수 있어요.
- **빨간 카드** 는 위험한 조작이에요(이미 있는 시보 덮어쓰기, 학교 전체 방송, 암전, 행사 중 씬 바꾸기 등). 실행을 누른 뒤 한 번 더 확인해요.

## 장비 다루기

강당 장비도 CUE 로 다룰 수 있어요.

- 콘솔: 씬, 페이더, 뮤트, 게인·EQ·컴프·에코 ([콘솔 세부 조절](/docs/onair-hall-processing))
- 조명: 장면, 전체 밝기, 암전, 조명별 밝기·색
- [강당 소리 교실 중계](/docs/onair-hall-relay), [페이더 공연](/docs/onair-fader-show) (지금은 CUE·MCP 로만 켜요)
- 녹음·녹화 시작·멈춤

## 첨부

채팅에 이미지·영상·음원·PDF 를 올릴 수 있어요. 송출이나 방송에 쓰려면 CUE 가 먼저 **파일 관리에 넣는 카드** 를 띄워요. 그 카드를 확인해야 파일이 들어가요.

| 종류 | 크기 |
| --- | --- |
| 이미지 | 20MB |
| PDF | 32MB |
| 소리 | 100MB |
| 영상 | 500MB |

## 한도와 권한

- 등록된 사람이면 누구나 물어볼 수 있어요.
- 조작은 **부원 이상** 만 돼요. 졸업·교사는 묻기와 화면 안내만 돼요.
- 하루에 쓸 수 있는 횟수가 사람마다 정해져 있어요(기본 60번). 한국 시간 자정에 다시 채워져요.
- 대화가 길어지면 새 대화를 열어요.
- 지우기, 장비 연결, 부원 관리, 서버 설정은 CUE 가 하지 않고 화면으로 안내해요.

<Callout type="warn" title="비상 상황">
실제 화재·비상이면 CUE 로 조작하지 말고 선생님께 먼저 알려요. 훈련·시험 방송은 확인 카드로 해요.
</Callout>
