ONAIR 는 학교 종과 교실 스피커를 다뤄요. 실수 하나가 학교 전체에 들려요. 아래는 꼭 지켜요.

## 서버 PC 의 값·파일은 건드리지 않기

- 서버 PC 에서 설정 파일이나 데이터 폴더를 열어 고치지 않아요.
- 서버 PC 화면의 ONAIR 창(송출·live 중계·녹화 창)을 닫거나 가리지 않아요.
- 서버 PC 를 끄거나 다시 시작하지 않아요. 필요하면 부장에게 말해요.

## 시보 안전장치

ONAIR 는 **종이 먼저** 예요. 시보는 제 시각에 울리거나, 못 울리면 아예 건너뛰어요. 늦게 울리지 않아요.

- 종 직전에는 TTS·음원 방송이 시작되지 않아요. 종까지 다 못 끝낼 방송은 "종이 곧 울려요"라며 막혀요.
- 마이크 방송과 강당 교실 중계는 종 약 20초 전에 저절로 끝나요.
- 시보를 고친 뒤 **적용하기** 를 누르지 않으면 서버에 반영되지 않아요.
- 시보 그룹이나 특별 시간표를 바꿀 때는 오늘 남은 종을 먼저 확인해요.

## 배포·재시작은 확인 받고

- ONAIR 업데이트와 서버 재시작은 부장·관리자 확인을 받고 해요.
- **다음 시보 8분 전부터는 하지 않아요.**
- 마이크 방송 중이면 업데이트가 스스로 멈춰요. 억지로 끄지 않아요.

## 송출 화면 켜 둔 채 두지 않기

- 다 쓴 송출 채널은 **송출 끄기** 로 대기 화면으로 돌려요.
- 외부 화면 공유는 **받기 끝내기** 까지 눌러 코드를 닫아요.
- live 채팅을 켰다면 행사가 끝난 뒤 꺼요.

## 강당에서

- **강당 스피커로 강당 소리를 중계하지 않아요.** 하울링이 나요. (ONAIR 가 기본으로 막아요.)
- **행사 중에 페이더 공연을 하지 않아요.** 모든 채널이 잠깐 뮤트돼요.
- 행사 중에는 씬을 사회자와 맞추지 않고 바꾸지 않아요.
- M-Track 의 **팬텀 전원** 을 켜지 않아요.
- 조명을 다 쓰면 **MCC 판넬 메인 차단기** 를 내려요.
- ONAIR 로 조명을 쓴 뒤에는 조명 케이블을 **Sunny 512 OUTPUT 1** 에 다시 꽂아요.

## 말로 조작할 때

- CUE 나 MCP 의 확인 카드·실행 요청은 **내용을 읽고** 눌러요. 특히 빨간 카드는 학교 전체나 행사 전체에 영향을 줘요.
- 실제 비상 상황이면 조작하지 말고 선생님께 먼저 알려요.
