폰이나 노트북 마이크로 교실 스피커에 방송해요. 방송실에 없어도 돼요.

<Figure src="/assets/onair/mic-main.webp" alt="메인 › 방송 › 마이크 탭" caption="메인 › 방송 › 마이크 탭" />

## 두 가지 방식

| 방식 | 설명 | 길이 |
| --- | --- | --- |
| 실시간 | 말하는 대로 바로 나가요 | 한 번에 최대 10분 |
| 녹음 후 방송 | 먼저 녹음하고 들어 본 뒤 내보내요 | 최대 2분 |

<Callout type="tip">
처음이거나 떨리면 **녹음 후 방송** 이 좋아요. 들어 보고 마음에 안 들면 다시 녹음하면 돼요.
</Callout>

## 마이크 방송 켜기

<Steps>
  <Step title="마이크 탭">
    **LIVE › 메인** 의 방송 칸에서 **마이크** 탭을 눌러요.
  </Step>
  <Step title="대상 고르기">
    방송할 교실·학년을 골라요. 고르지 않으면 시작할 수 없어요.
  </Step>
  <Step title="효과·딩동댕">
    효과를 고르고, 앞뒤에 딩동댕을 넣을지 정해요.
  </Step>
  <Step title="시작">
    **실시간** 이면 **마이크 켜기**, **녹음 후 방송** 이면 **녹음 시작** → **들어보기** → **방송하기** 순서예요.
  </Step>
</Steps>

처음 쓸 때는 브라우저가 마이크 권한을 물어요. **허용** 해야 해요.

## 음질 (효과)

| 효과 | 소리 |
| --- | --- |
| 방송 마이크 (기본) | 낮은 웅웅거림과 말 사이 잡음을 줄이고, 목소리를 또렷하게, 크기를 고르게 맞춰요 |
| 강당 울림 | 방송 마이크에 짧은 울림을 더해요 |
| 없음 | 크기만 맞춰요 |

- 마이크와 입 사이는 한 뼘쯤 두고 말해요.
- 스피커가 켜진 교실 안에서 방송하면 소리가 다시 마이크로 들어가 하울링이 날 수 있어요. 방송하는 곳 스피커는 대상에서 빼요.

## 끝나면 끄기

실시간은 **끝내기** 를 눌러요. 끝 딩동댕이 울리고 스피커가 원래대로 돌아가요.

아래 경우에는 **저절로 끝나요.**

| 메시지 | 까닭 |
| --- | --- |
| 종이 울릴 시간이라 끝났어요 | 다음 시보 약 20초 전에 끝나요. 종이 먼저예요 |
| N분이 지나 끝났어요 | 최대 시간이 지났어요 |
| 소리가 오지 않아 끝났어요 | 마이크 소리가 15초 동안 안 왔어요 |
| 연결이 끊겨 마이크 방송이 끝났어요 | 와이파이가 끊겼어요 |

## 못 켤 때

| 메시지 | 할 일 |
| --- | --- |
| 다른 방송이 진행 중이에요 | 한 번에 한 방송만 돼요. 지금 방송이 끝난 뒤 다시 해요 |
| ○○ 종이 곧 울려요 | 종까지 30초도 안 남으면 켜지지 않아요. 종이 끝난 뒤 해요 |
| 마이크 방송 권한이 없어요 | 부원 이상만 쓸 수 있어요 |
| 서버 소리 장치를 쓸 수 없어요 | 서버 PC 문제예요. 부장에게 알려요 |

<Callout type="info">
마이크 방송 중에는 강당 교실 중계, TTS, 선생님 방송을 함께 할 수 없어요. 서버 업데이트도 마이크 방송이 끝날 때까지 기다려요.
</Callout>
