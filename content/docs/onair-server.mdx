ONAIR 는 **방송실의 서버 PC** 한 대에서 돌아가요. 이 PC 가 꺼지면 ONAIR 도, PC 로 울리는 시보도 멈춰요.

## 서버 PC 가 하는 일

| 하는 일 | 설명 |
| --- | --- |
| ONAIR 서버 | 컨트롤 화면·앱·CUE·MCP 가 모두 이 서버에 붙어요 |
| 시보 | 정해 둔 시각에 종 소리를 스피커로 내보내요 |
| 방송 | TTS·마이크·음원 방송을 방송 앰프로 내보내요 |
| 송출 화면 녹화 | 'ONAIR REC' 창을 띄워 송출 채널을 녹화해요 |
| live 중계 | 학생 live 화면용으로 송출 채널을 찍어 올려요 |
| 강당 연결 | 강당 노트북을 거쳐 콘솔·조명·녹음 장비와 이야기해요 |
| OFFAIR | 이 가이드북(위키)도 같은 PC 에서 돌아요 |

## 켜고 끄기

- 서버 PC 는 **늘 켜 둬요.** 끄거나 다시 시작하면 그동안 시보가 울리지 않을 수 있어요.
- 서버 PC 화면에 전체 화면으로 떠 있는 ONAIR 창(송출·live 중계·녹화 창)을 닫거나 가리지 않아요. 가리면 그 화면이 live 나 녹화에 그대로 찍힐 수 있어요.
- 서버 PC 에서 다른 프로그램을 켜거나 설정을 바꾸지 않아요.

## 업데이트·재시작

ONAIR 를 새 버전으로 올리거나 서버를 다시 켜는 일은 **부장·관리자** 가 해요.

<Callout type="warn" title="종 8분 전에는 하지 않아요">
- 업데이트·서버 재시작은 **다음 시보 8분 전부터는 하지 않아요.** 재시작 도중에 종 시각이 오면 그 종이 안 울려요.
- **마이크 방송 중** 이면 업데이트 스크립트가 스스로 멈추고 기다려요.
- 업데이트 창에 다음 종까지 남은 시간이 나오니 꼭 읽고 진행해요.
</Callout>

## 원격 접속

서버 PC 원격 접속은 부장·관리자만 해요. 접속 정보(주소·비밀번호 등)는 이 공개 가이드북에 적지 않아요. 필요하면 부장에게 물어봐요.

<Callout type="note">
부원은 서버 PC 에 직접 들어갈 일이 거의 없어요. 대부분은 컨트롤 화면, CUE, [ONAIR MCP](/docs/onair-mcp)로 할 수 있어요.
</Callout>
