**ONAIR** 는 부산소프트웨어마이스터고 방송부가 교실 스피커 방송, 시보, 송출 화면, 강당 음향·조명·녹음을 원격으로 다루려고 만든 시스템이에요. 방송실에 직접 있지 않아도 컨트롤 화면이나 앱에서 실제 장비를 조작할 수 있어요.

<Figure src="/assets/onair/00-main.webp" alt="ONAIR 컨트롤 메인 화면" caption="ONAIR 컨트롤 메인 화면. 왼쪽이 메뉴, 오른쪽이 작업 영역" />

<Callout type="info">
모든 조작은 방송실 [서버 PC](/docs/onair-server)를 거쳐 실제 장비(스피커·송출 화면·강당 장비)로 가요. 강당 장비는 강당 노트북을 한 번 더 거쳐요.
</Callout>

## 쓰는 곳

| 어디서 | 무엇 |
| --- | --- |
| 컨트롤 화면 (웹·앱) | 모든 기능. [접속과 화면 구성](/docs/onair-access) |
| CUE 도우미 | 컨트롤 화면 안에서 말로 묻고 조작. [CUE 도우미](/docs/onair-cue) |
| 내 Claude·ChatGPT 앱 | ONAIR 를 커넥터로 붙여 말로 조작. [ONAIR MCP](/docs/onair-mcp) |
| 선생님 화면 | 선생님이 방송부에 요청. [선생님 요청](/docs/onair-teacher) |
| 학생 live 화면 | 학생이 송출 화면을 폰으로 보기. [학생 기기 화면](/docs/onair-live) |
| 외부 공유 화면 | 외부 발표자가 노트북 화면 보내기. [외부 화면 공유](/docs/onair-share) |

## 공통 팁

<Callout type="tip">
- **시보는 적용하기** 를 눌러야, **송출·현수막은 고르는 즉시** 반영돼요.
- 음원·이미지·영상은 먼저 **파일** 메뉴에 올려 둬야 각 메뉴에서 고를 수 있어요.
- 다 쓴 송출 채널은 **송출 끄기** 로 내려 둬요.
- 종이 먼저예요. 종 직전에는 방송이 막히거나 저절로 끝나요.
- 처음이면 [하면 안 되는 것](/docs/onair-donts)부터 읽어요.
</Callout>
