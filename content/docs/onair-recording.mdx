**HALL › 녹음·녹화** 한 화면에서 콘솔 소리 녹음과 송출 화면 녹화를 함께 해요. 휴대폰으로 찍은 행사 영상의 소리를 콘솔 녹음으로 바꿔 끼울 수도 있어요.

<Figure src="/assets/onair/recording.webp" alt="컨트롤 › 녹음·녹화" caption="HALL › 녹음·녹화. 화면과 소리를 고르고 시작, 아래는 목록" />

## 무엇을 고르나

| 화면 | 소리 | 결과 |
| --- | --- | --- |
| 없음 | 강당 콘솔 | **소리만** (콘솔 녹음 WAV) |
| CH1~5 중 하나 | 소리 없음 | **영상만** (그 채널 화면 MP4) |
| CH1~5 중 하나 | 강당 콘솔 | **영상+소리** (끝나면 MP4 하나로 합쳐 줘요) |

채널을 고르면 그 채널에 연결된 공간의 콘솔이 소리로 저절로 골라져요. 바꿀 수도 있어요.

<Callout type="info">
콘솔 녹음은 강당 노트북의 M-Track 으로 들어와요. 연결은 [강당 녹음 장비 연결](/docs/onair-recording-setup)을 봐요.
</Callout>

## 녹화 시작·끝

<Steps>
  <Step title="고르기">
    화면과 소리를 골라요. 녹음 이름을 적어요(예: 2026 졸업식).
  </Step>
  <Step title="시작">
    빨간 버튼을 눌러요. 녹음·녹화 중에는 고른 것을 바꿀 수 없어요.
  </Step>
  <Step title="멈추기">
    다시 누르면 "한 번 더 누르면 멈춰요"가 떠요. 한 번 더 눌러 멈춰요.
  </Step>
  <Step title="가져오기">
    멈추면 서버가 노트북에서 녹음을 받아 와요. 1시간 녹음이면 몇 분 걸려요.
  </Step>
</Steps>

## 행사 날 순서

1. **행사 시작 10분 전에 녹음을 시작해요.** 끝날 때까지 멈추지 않아요. 멈췄다 다시 켜면 파일이 둘이 돼요.
2. 휴대폰으로 영상을 찍는 사람은 **녹음이 시작된 뒤** 찍기 시작해요.
3. 시작하자마자 사회자 마이크 가까이에서 **손뼉 한 번** 쳐요. 나중에 영상과 녹음을 맞출 때 확실해져요.
4. 끝나면 녹음을 멈춰요.

## 휴대폰 영상 합치기

휴대폰 마이크로 담긴 웅웅거리는 소리 대신 콘솔 녹음을 영상에 넣어요. 화면의 **휴대폰 영상 합치기** 를 열어요.

<Steps>
  <Step title="영상 올리기">
    휴대폰 영상(MP4·MOV, 16GB 까지)을 올려요. PC 로 옮긴 뒤 PC 브라우저에서 올리는 게 빨라요.
  </Step>
  <Step title="녹음 고르기">
    같은 행사의 녹음을 골라요.
  </Step>
  <Step title="소리 고르기">
    둘 다 / 마이크만 / 음악만 중에 골라요. 현장음 섞기(끔·약하게·보통)로 박수 소리를 살짝 깔 수 있어요.
  </Step>
  <Step title="합치기">
    진행률이 다 차면 MP4 를 받아요. 1시간 영상이면 2~3분 걸려요. 화질은 원본 그대로예요.
  </Step>
</Steps>

입 모양과 소리가 어긋나 보이면 미세 조정(±ms)으로 맞춰요. 끝으로 갈수록 어긋나면 편집한 영상을 올린 것이니 원본 영상을 올려요.

## 목록

| 버튼 | 하는 일 |
| --- | --- |
| 듣기 · 보기 | 화면에서 바로 재생 |
| 받기 | 파일 내려받기 |
| 이름 바꾸기 | 목록 이름 바꾸기 |
| 다시 가져오기 | 노트북에서 녹음을 받다가 끊겼을 때 |
| 다시 만들기 | 영상+소리 합치기가 실패했을 때 |
| 지우기 | 부장만. 되돌릴 수 없어요 |

## 파일 크기

| 무엇 | 크기 |
| --- | --- |
| 콘솔 녹음 | 1시간에 약 1GB |
| 녹음 한 파일 최대 | 약 3시간 45분 (넘기 전에 저절로 멈춰요) |
| 화면 녹화 | 1시간에 약 3.6GB (대부분 멈춘 화면이라 실제로는 더 작아요) |

화면 위에 서버의 남은 공간과 몇 시간 더 녹음할 수 있는지 보여요.

## 주의할 점

- 화면 녹화는 **서버 PC 가 직접** 해요. 서버 PC 에 'ONAIR REC' 창이 떠요. 그 창을 닫거나 최소화하지 않아요. 녹화가 멈춰요.
- 녹화 중에는 서버 PC 화면을 건드리지 않아요. 다른 창이 가리면 그 창이 찍힐 수 있어요.
- 한 번에 하나만 녹음·녹화할 수 있어요.
- 노트북에도 녹음 원본이 남아요. 서버로 못 받아 와도 '다시 가져오기'로 살릴 수 있어요.

| 할 수 있는 일 | 누가 |
| --- | --- |
| 시작·멈춤·듣기·받기·영상 합치기 | 부원 이상 |
