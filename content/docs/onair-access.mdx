## 들어가는 곳

| 어디서 | 어떻게 |
| --- | --- |
| 웹 브라우저 | **onair.bssmcast.com** 에 들어가 이메일로 로그인해요 |
| 데스크톱 앱 | 부장에게 받은 초대 QR 이나 8자리 코드로 등록해요 |

같은 사람이 기기를 여러 대 쓸 수 있어요. 사이드바 아래 내 이름 카드 › **내 기기** › **다른 기기 추가** 로 새 기기를 붙여요.

## 로그인

<Steps>
  <Step title="부장에게 초대 받기">
    부장이 **관리 › 부원** 에서 초대를 만들어요. QR 은 24시간, 8자리 코드는 30분 동안 한 번 쓸 수 있어요.
  </Step>
  <Step title="등록하기">
    앱에서 QR 을 읽거나 코드를 넣고, 이름·기수·메일 아이디를 적어요. 그러면 **승인 대기** 가 돼요.
  </Step>
  <Step title="승인 기다리기">
    부장이 역할을 골라 승인하면 그 권한으로 쓸 수 있어요.
  </Step>
</Steps>

<Callout type="info" title="웹으로 들어올 때">
부원이 되면 내 개인 메일과 @bssmcast.com 주소가 로그인 허용 목록에 저절로 들어가요. 그 메일로 로그인하면 돼요. 다른 메일로는 들어올 수 없어요.
</Callout>

## 권한 단계

| 역할 | 할 수 있는 일 |
| --- | --- |
| 최고 관리자 | 전부 + 서버·Cloudflare 설정 |
| 부장 | 부원 일 전부 + 현장 세팅(장비 연결·채널·조명 목록), 부원 초대·승인·역할 바꾸기, 선생님 승인 |
| 부원 | 모든 조작. 방송·송출·스피커·시보·믹서·조명·녹음·녹화 |
| 졸업 | 보기만 |
| 교사 | 선생님 화면(요청)만 |
| 승인 대기·미등록 | 보기만 |

- 2학년이 1년 동안 부장을 맡아요. 부장은 다른 부원을 부장으로 임명할 수 있어요.
- 마지막 부장은 스스로 내려놓을 수 없어요. 다음 부장을 먼저 임명해요.
- 졸업하면 보기 전용이 돼요. 내보내기 하면 더는 못 들어와요.

## 화면 구성

<Figure src="/assets/onair/access-main.webp" alt="ONAIR 컨트롤 메인 화면" caption="ONAIR 컨트롤 메인 화면. 왼쪽 메뉴, 가운데 방송, 오른쪽 네트워크 상태와 스피커" />

왼쪽 메뉴는 네 묶음이에요.

| 묶음 | 메뉴 | 하는 일 |
| --- | --- | --- |
| LIVE | 메인 | TTS·마이크 방송, 스피커, 네트워크 상태 |
| | 송출 | 송출 화면(CH1~5), 현수막, 외부 화면 공유 |
| | 요청함 | 선생님 요청 (부원 이상) |
| | 스피커 지도 | 학교 층별 스피커 보기 |
| HALL | 오디오 | 강당·다목적홀 콘솔, 자동 음향 |
| | 조명 | 강당 조명, 음악 조명 |
| | 녹음·녹화 | 콘솔 녹음, 송출 화면 녹화, 영상 합치기 |
| SETUP | 시보 | 시보 시간표 (부장에게는 예약 현황·야간 절전 탭도) |
| | 파일 | 이미지·영상·음원·PPT 올리기 |
| | 방송부 | 방송부 명단, 내 소개 |
| ADMIN | 관리 · 로그 | 부원·기기·장비·접근 기록 (부장 이상) |

메뉴 아래 **CUE** 단추로 [CUE 도우미](/docs/onair-cue)를 열어요.
