강당 조명을 켜고, 조명 콘솔(Sunny 512)이나 ONAIR 로 조종하기 위한 **실제 연결 순서** 예요. 조명 화면 쓰는 법은 [강당 조명](/docs/onair-lighting)을 봐요.

## 조명 전원 (MCC 판넬)

조명 전원은 **무대 준비실의 MCC 판넬** 에서 켜요.

<Steps>
  <Step title="메인 차단기 올리기">
    MCC 판넬의 **메인 차단기** 를 올려요.
  </Step>
  <Step title="무대조명 차단기 올리기">
    **무대조명** 차단기를 올려요.
  </Step>
  <Step title="각 장치 켜기">
    조명 콘솔과 필요한 조명 장치를 켜요.
  </Step>
</Steps>

<Callout type="warn" title="다 쓰면 메인 차단기를 내려요">
행사가 끝나면 조명을 끄고 **메인 차단기** 까지 내려요. 켜 둔 채 퇴실하지 않아요.
</Callout>

## 조명 신호가 가는 길

```
Sunny 512 조명 콘솔 OUTPUT 1 (수 단자)
   → 조명 케이블
   → MCC 판넬 맨 위 CAC 아이솔레이션 DMX 스플리터 (DMX In, 5핀)
   → Out 1~3
   → LED PAR · LED 무빙 라이트
```

- 스플리터는 MCC 판넬 **맨 위** 에 있어요. 들어온 신호 하나를 Out 1~3 으로 나눠 조명들에 보내요.
- 평소에는 Sunny 512 콘솔로 조종해요. 콘솔 OUTPUT 1 에 조명 케이블이 꽂혀 있어요.

## ONAIR 로 조명 쓰기

ONAIR 는 강당 노트북에 꽂은 **USB-DMX 케이블** 로 조명 신호를 보내요. 이때는 콘솔 대신 노트북이 스플리터에 신호를 넣어요.

| 준비물 | 설명 |
| --- | --- |
| USB-DMX 케이블 | 강당 노트북 USB 에 꽂아요. 끝이 XLR 3핀 **암** 이에요 |
| XLR 3핀 수-수 젠더 | 조명 케이블 끝도 3핀 **암** 이라 둘을 이으려면 필요해요 |

<Callout type="note" title="젠더는 사는 중이에요">
수-수 젠더가 아직 없어요. 젠더가 오기 전에는 ONAIR 로 조명을 켤 수 없고, Sunny 512 콘솔로만 조종해요.
</Callout>

<Steps>
  <Step title="콘솔에서 케이블 빼기">
    Sunny 512 **OUTPUT 1** 에서 조명 케이블을 뽑아요.
  </Step>
  <Step title="젠더로 잇기">
    조명 케이블 끝에 **수-수 젠더** 를 끼우고, 그 반대쪽에 USB-DMX 케이블을 꽂아요.
  </Step>
  <Step title="노트북에 꽂기">
    USB-DMX 케이블을 강당 노트북 USB 에 꽂아요. 노트북에서는 COM3 로 잡혀요.
  </Step>
  <Step title="ONAIR 에서 확인">
    **HALL › 조명** 상태가 **DMX online** 인지 봐요. 조명 하나를 올려 실제로 켜지는지 확인해요.
  </Step>
</Steps>

<Callout type="warn" title="끝나면 원래대로">
젠더와 USB-DMX 케이블을 빼고, 조명 케이블을 **Sunny 512 OUTPUT 1** 에 다시 꽂아요. 다음 사람이 콘솔로 바로 쓸 수 있게요.
</Callout>

ONAIR 쪽 연결 값(연결 방식 강당 노트북, 변환기 USB-DMX 케이블, COM 포트)은 부장이 **조명 › 현장 세팅** 에서 이미 저장해 뒀어요. USB 구멍을 바꿔 COM 번호가 달라지면 부장에게 알려요.

## 조명기 채널표

조명기마다 DMX 채널 뜻이 정해져 있어요. 콘솔로 조종하거나 ONAIR 조명 목록을 만들 때 봐요.

### LED PAR (11채널)

| 채널 | 뜻 |
| --- | --- |
| 1 | 마스터(전체 밝기) |
| 2 | 스트로브 |
| 3 | 사운드(소리 반응) |
| 4 | 스피드 |
| 5~10 | 빨강·초록·파랑·흰색·주황·보라 (R·G·B·W·O·P) |
| 11 | 줌 |

### LED 무빙 라이트 (24채널)

| 채널 | 뜻 |
| --- | --- |
| 7·8 | 밝기. **이 둘을 먼저 올려야** 빛이 나와요 |
| 1~6 | 색 |
| 21 | 좌우 움직임 |
| 23 | 상하 움직임 |
| 18 | 포커스 |
| 20 | 줌 |

<Callout type="tip">
LED PAR 는 1번(마스터)이 0 이면 색을 올려도 안 켜져요. 무빙 라이트는 7·8번이 0 이면 안 켜져요. 조명이 안 들어오면 이것부터 봐요.
</Callout>

## 안 될 때

| 증상 | 확인 |
| --- | --- |
| 조명이 아예 안 켜짐 | MCC 판넬 메인 차단기와 무대조명 차단기, 각 장치 전원 |
| 콘솔로 조종이 안 됨 | 조명 케이블이 Sunny 512 OUTPUT 1 에 꽂혀 있는지 |
| ONAIR 화면이 DMX offline | 강당 노트북 전원, ONAIR Bridge 창, USB-DMX 케이블 USB |
| ONAIR 는 online 인데 조명이 안 따라옴 | 젠더 연결, 위 채널표의 마스터·밝기 채널 |
