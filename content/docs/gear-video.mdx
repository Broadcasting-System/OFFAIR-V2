## 기본 흐름

어떤 소스든 **프리뷰에 올리고 → CUT 이나 TAKE** 로 송출합니다.

<Figure src="/assets/gear/VIDEO MIXER/송출 전환1.webp" alt="비디오 스위쳐" caption="프로그램(지금 송출) · 프리뷰(다음 송출) 채널" />

<Steps>
  <Step title="미리보기 확인">
    영상 미리보기 창에서 보낼 화면이 잘 들어오는지 봅니다.
  </Step>
  <Step title="프리뷰 지정">
    비디오 스위쳐에서 다음에 보낼 채널을 프리뷰로 고릅니다. 고를 수 있는 채널은 외부 입력 1~4, DDR1·2, Still(이미지), PPT, PC, M1~M4 입니다.
  </Step>
  <Step title="송출">
    **CUT** 은 바로 바꾸고, **TAKE** 는 전환 효과를 넣어 바꿉니다. T-BAR 로 직접 밀어도 됩니다.
  </Step>
</Steps>

외부 입력은 미리보기 화면을 **두 번 클릭**해도 바로 나갑니다. 송출 중인 채널은 **빨간 테두리**, 직전 채널은 **녹색 테두리**입니다.

| 전환 속도 | 시간 |
| --- | --- |
| S | 약 2초 |
| M | 약 1초 |
| F | 약 0.5초 |

<Callout type="note">
M1~M4 · PC · PPT 로 바꿀 때는 전환 효과가 들어가지 않습니다.
</Callout>

## 소스별로 띄우는 법

| 보낼 것 | 하는 법 |
| --- | --- |
| 카메라·노트북 (HDMI) | 미리보기에 화면이 보이면 그대로 프리뷰 → CUT/TAKE |
| 동영상 (DDR) | 모드 프리셋 DDR1·2 탭 → 파일 열기 → 갤러리에서 두 번 클릭 → 송출 |
| 이미지 (Still) | 이미지 탭 → 파일 열기 → 두 번 클릭 → 송출. jpg · png · bmp · tiff |
| PPT | PPT 탭 → 파일 열기 → 페이지 두 번 클릭, 다음 장은 <Kbd>Enter</Kbd> · <Kbd>Space</Kbd> |
| PC 화면 | 프로그램을 최소화하고 띄울 화면을 연 뒤 <Kbd>Alt</Kbd> + <Kbd>F11</Kbd>, 돌아올 때 <Kbd>Alt</Kbd> + <Kbd>F12</Kbd> |
| 유튜브 | 입력 5·6번 기어 → IP 수신 모드 → 유튜브 주소 붙여넣기 |
| USB 카메라 | 입력 5·6번 기어 → Device 탭 → USB 입력 모드, 해상도·오디오 지정 |

### 동영상 끝난 뒤 상태

DDR 미리보기 창의 기어에서 송출이 끝난 뒤 어떻게 기다릴지 정합니다.

| 모드 | 동작 |
| --- | --- |
| 처음 | 다시 틀면 항상 처음부터 |
| 일시정지 | 멈춘 채로 대기 |
| 재생 | 계속 재생 상태로 대기 |
| 반복 | 송출 중 반복 재생 |

<Callout type="tip">
효과·소리·동영상이 들어간 **슬라이드 쇼**는 PPT 탭 대신 **PC 화면 송출**로 내보내세요. PPT 탭은 각 장을 그림으로 바꿔 보내서 효과가 빠집니다.
</Callout>

<Callout type="warn">
USB 카메라가 목록에 안 보이면 드라이버 설치를 확인하거나 PC 를 재부팅하세요.
</Callout>
