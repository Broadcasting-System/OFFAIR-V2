강당 행사(졸업식·축제·발표회 등) 때 쓰는 점검표예요. 쓰지 않는 기능은 건너뛰어요.

## 하루 전

- 행사 시간표와 그 시간의 **시보** 를 확인해요. 행사 중에 종이 울리면 안 되면 부장과 시보를 미리 바꿔요.
- 송출할 영상·이미지·PPT·음원을 **파일** 에 올려 둬요. 영상은 변환이 끝났는지 봐요.
- 교실 중계를 할지, 어느 교실로 몇 분 할지 정해요.
- 녹음·녹화를 할지, 어느 채널을 찍을지 정해요.
- 조명을 ONAIR 로 쓸지 콘솔로 쓸지 정해요. ONAIR 로 쓰려면 XLR 수-수 젠더가 있어야 해요.
- 외부 발표자가 노트북 화면을 띄우면 [외부 화면 공유](/docs/onair-share) 방법을 미리 알려 줘요.

## 시작 1시간 전

- 강당 노트북을 켜고 **ONAIR Bridge** 창이 떴는지 봐요.
- **HALL › 오디오** 에서 **믹서 연결됨** 인지 봐요. 마이크마다 소리를 내 보고 게인을 맞춰요.
- M-Track 연결과 **팬텀 전원 꺼짐** 을 확인하고, **HALL › 녹음·녹화** 미터가 움직이는지 봐요.
- 무대 준비실 **MCC 판넬** 메인 차단기 → 무대조명 차단기를 올리고 조명을 켜요.
- 쓸 조명 장면을 한 번씩 불러 봐요.
- 송출 채널에 첫 화면을 띄워 프로젝터에서 확인해요.
- 페이더 공연을 할 거면 **지금(시작 전)** 해요.

## 시작 직전과 행사 중

- **시작 10분 전에 녹음을 시작해요.** 끝날 때까지 멈추지 않아요.
- 시작하자마자 사회자 마이크 가까이에서 손뼉 한 번 (영상 합치기용).
- 교실 중계를 켰다면 다음 시보 직전에 저절로 끝나요. 종이 지나면 다시 켜요.
- 씬 바꾸기·암전은 사회자·진행과 맞춘 뒤에 해요.
- live 채팅을 켰다면 한 사람이 채팅을 봐요.
- 서버 PC 화면을 건드리지 않아요 (녹화 중).

## 끝나고 정리

- 녹음·녹화를 멈추고, 목록에서 다 받아 왔는지 봐요.
- 교실 중계를 멈춰요.
- 송출 채널을 **송출 끄기** 로 내리고, 외부 화면 공유는 **받기 끝내기**.
- live 채팅을 꺼요.
- 바꾼 게인·EQ·FX 를 원래대로 돌리거나 기본 씬을 다시 불러요.
- 조명을 끄고 **MCC 판넬 메인 차단기** 를 내려요.
- ONAIR 로 조명을 썼다면 조명 케이블을 **Sunny 512 OUTPUT 1** 에 다시 꽂아요.
- 바꿨던 시보를 원래대로 돌려요.
