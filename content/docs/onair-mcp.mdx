내가 쓰는 **Claude** 나 **ChatGPT** 앱에 ONAIR 를 연결하면, 그 앱의 채팅에서 말로 ONAIR 를 써요. CUE 도우미와 같은 기능을 내 앱에서 쓰는 거예요.

- "지금 송출 뭐 나가?"
- "1학년 스피커 켜 줘"
- "이 시간표 사진으로 시보 만들어 줘"
- "강당 MIC 3 게인 조금 올려 줘"

## 연결하기

연결 주소는 하나예요.

```
https://mcp.bssmcast.com/mcp
```

### Claude (웹·데스크톱·모바일)

<Steps>
  <Step title="커넥터 추가">
    설정 › 커넥터 › **커스텀 커넥터 추가** 를 눌러요.
  </Step>
  <Step title="주소 넣기">
    이름은 `ONAIR`, 주소는 위 주소를 넣고 추가해요.
  </Step>
  <Step title="ONAIR 로그인">
    뜨는 창에서 ONAIR 에 쓰는 이메일로 로그인하고 **연결하기** 를 눌러요.
  </Step>
  <Step title="써 보기">
    새 대화에서 "ONAIR 지금 상태 알려 줘"라고 해 봐요.
  </Step>
</Steps>

### ChatGPT

설정 › 앱과 커넥터 › 고급 › **개발자 모드** 를 켜고 커넥터를 만들어요. 주소는 같고, 인증은 OAuth 를 골라요. 로그인 창에서 **연결하기** 를 누르면 끝이에요. 요금제나 지역에 따라 메뉴 이름이 조금 다를 수 있어요.

<Callout type="info" title="로그인은 ONAIR 계정으로">
처음 연결할 때 한 번 ONAIR 로그인을 해요. 부원으로 등록된 이메일이어야 해요. 로그인이 안 되면 부장에게 내 이메일이 부원 기록에 있는지 물어봐요.
</Callout>

## 바꾸는 일은 확인 뒤에

상태를 묻는 건 바로 답해요. 스피커·송출·시보·강당 장비처럼 **무언가 바꾸는 일은 바로 하지 않아요.**

<Steps>
  <Step title="요청">
    "2학년 교실에 점심 안내 TTS 해 줘"라고 말해요.
  </Step>
  <Step title="앱이 내용을 보여 줌">
    무엇을 어디에 할지 보여 주고 "이대로 할까요?"라고 물어요.
  </Step>
  <Step title="내 대답">
    "응, 해 줘"라고 하면 그때 실행돼요. "아니"라고 하면 취소돼요.
  </Step>
</Steps>

- 실행 대기 요청은 **10분** 안에, **만든 사람만**, **한 번만** 실행할 수 있어요.
- 학교 전체 방송·암전처럼 위험한 일은 처음에 "바로 해"라고 했어도 한 번 더 물어요.
- 앱이 "했어요"라고 말하기 전에 실제 결과를 꼭 확인해요.

## 할 수 있는 일

| 분야 | 예 |
| --- | --- |
| 상태 보기 | 송출 채널, 현수막, 시보, 스피커, 강당 장비, 녹음 상태 |
| 소리 방송 | TTS·음원 방송, 스피커 켜기·끄기 |
| 시보 | 시보 보기, 몇 개 고치기, 시간표 사진으로 새로 만들기, 특별 시간표 켜기·끄기 |
| 송출 화면 | 파일·유튜브·타이머 띄우기, 재생 조작, 송출 끄기, 예약 송출 |
| 현수막 | 글자·점수보드·이미지·저장한 현수막 띄우기 |
| 강당 | 콘솔 씬·페이더·뮤트·게인·EQ·컴프·에코, 조명, [교실 중계](/docs/onair-hall-relay), [페이더 공연](/docs/onair-fader-show) |
| 녹음·녹화 | 시작·멈춤, 이름 바꾸기, 영상 합치기 |
| 요청함·화면 공유·live 채팅 | 선생님 요청 수락·거절, 외부 화면 공유 허용, 채팅 켜기 |
| 파일 보기 | 이미지·슬라이드·영상 장면·음원 파형, 지금 송출 화면을 그림으로 보기 |
| 문서 찾기 | 이 가이드북(OFFAIR)을 찾아 읽고 답하기 |

### 파일 보기

"지금 CH1 에 뭐 떠 있어?", "현수막 이미지 보여 줘"라고 하면 그림으로 가져와 보여 줘요. 영상은 장면 몇 장, 음원은 파형 그림으로 보여 줘요. 앱은 소리를 들을 수 없어요.

원본 파일(mp4·mp3)이 필요하면 앱이 **원본 링크** 를 줘요. 그 링크는 내 브라우저에서 ONAIR 로그인 뒤 열려요.

## 할 수 없는 일

아래는 앱에서 하지 않아요. **ONAIR 컨트롤 화면** 에서 해요.

- 파일 새로 올리기 (컨트롤 화면 › 파일)
- 지우기
- 장비 연결·현장 세팅
- 부원·선생님 계정 관리
- 서버 설정

## 권한

내 ONAIR 권한 그대로예요.

| 역할 | MCP 에서 |
| --- | --- |
| 부장·부원 | 보기·질문·조작 |
| 졸업·교사 | 보기·질문만 |
| 승인 대기·미등록 | 못 써요 |

- 한 사람이 1분에 120번까지 부를 수 있어요.
- 내가 한 일은 ONAIR 접근 로그에 내 이름으로 남아요.

## 끊기

- 앱의 커넥터 설정에서 지우면 끊겨요.
- **30일** 동안 안 쓰면 저절로 끊겨요. 다시 연결하면 돼요.
- 졸업하면 조작 도구가 사라지고, 내보내기 되면 아예 못 써요.

<Callout type="warn" title="조심할 것">
- 시보 직전이나 마이크 방송 중에는 서버가 일부 조작을 미루거나 막아요. 앱이 알려 주는 까닭을 읽어요.
- 화재 같은 실제 비상 상황이면 앱으로 조작하지 말고 선생님께 먼저 알려요.
- 내 앱 대화 기록에 학교 일정·파일 내용이 남아요. 앱을 다른 사람과 같이 쓰지 않아요.
</Callout>
